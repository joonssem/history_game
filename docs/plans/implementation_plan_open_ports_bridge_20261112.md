## 의도 (사용자, 2026-11-12)
- 현재 앱(`joseon-open-ports/`)은 현 교과서 중심 협동 학습이므로 **그대로 둔다**.
- 현 교과서는 역사 내용이 부실해 학생이 이해하기 어렵다. 그래서 교과서 활동을 먼저 하고, **전후·사이에 빠진 부분을 옛 교과서 활동 중 학생들이 재미있게 했던 것으로 게임처럼 추가**한다. 순서는 교과서 → 흥선대원군 → 강화도 조약 → 근대 문물.
- 현 교과서 범위를 넘는 내용이 많다(원문 검색 결과: 대원군·척화·양요·세도·조약 조항 0건). 범위를 넘는 것은 허용하되 화면에 "교과서 밖 보충"임을 표시한다.

## 사용자 결정 6가지
1. 옛 자료는 그대로 쓰지 않고 손본다.
2. 카톡 대화는 **"가상 대화"라고 표시**한다.
3. 근거는 웹검색으로 확인하고 출처도 웹검색으로 단다(아래 확인 결과).
4. 조약 1조처럼 널리 알려진 해석은 단정하지 않고 **"~라고 해석된다/볼 수 있다"** 어투로 쓴다.
5. 빈칸은 문장이 아니라 **간단한 단어**만 넣게 한다. 학교폭력 합의문의 영수·철수는 **00, XX**처럼 알아볼 수 없는 이름으로 바꾼다. 단어 입력에는 **초성 힌트**를 준다.
6. 이 자료도 kidary01 선생님 자료이고, 숨은 그림 이미지는 대한민국 역사 이미지를 그 선생님이 편집한 것이다. **이미지는 SVG로 바꾸지 않고 원본 그대로** 쓴다(알아보기 어렵고 오개념 위험).

## 활동 설계안 (초안)
공통: 정적 페이지, 이름·학번 없음, 기록은 기기 안(localStorage), 점수 없음, 입력은 **단어 한 개 + 초성 힌트**(예: `ㅅㅅㄴ`), 막힐 때 교사 확인 숫자 탈출구는 사라진 그림 게임과 같은 방식. 입력 판정은 `missing-painting/app.js`의 `norm()` 방식을 재사용할지 검토한다.

1. **흥선대원군 — 가상 카톡 대화 + 척화비 사건 조각** (옛 1차시)
   - 대화 4개(양반 군포·인재 등용·서원 정리·경복궁)를 **"가상 대화(교사가 지은 이야기)"** 표시와 함께 보여 주고, 핵심 단어를 초성 힌트로 채운다. 대화 속 사실은 위 표의 확인된 것만 쓴다.
   - 척화비: 병인양요 → 신미양요 사건 조각을 눌러 순서대로 배열하는 방식(㉠~㉩). 기기 터치에 맞는 선택식으로 바꾼다.
2. **강화도 조약 — 이상한 합의문** (옛 2차시)
   - 학교폭력 합의문 비유는 유지하되 인물을 **00, XX**로 바꾼다. 학교폭력 소재를 5학년에 쓸지는 사용자 판단으로 남긴다(대안: 학급 규칙·게임 약속 등 다른 비유).
   - 조약 1·7·10조: 단어 빈칸(예: 청·측량·처벌)과 초성 힌트. 설명 문장은 위 표의 완곡한 어투.
3. **숨은 근대 문물 찾기** (옛 3차시)
   - 11개 설명 → 이름 맞히기(초성 힌트) → 원본 그림(`image01~03.png`)에서 찾아 체크. 이미지는 **원본 그대로**. 고유명(광혜원·배재학당·단발령·석조전·기차)은 현 교과서에 없으므로 교과서 밖 보충으로 표시하고, 양복·전화 서술은 위 표대로 줄인다.
