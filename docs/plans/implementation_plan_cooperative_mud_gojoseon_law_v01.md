## 1. 목적

19명의 학생이 5개 모둠으로 나뉘어 서로 다른 역할 정보와 이해관계를 읽고, 실제 말로 정보를 공유한 뒤 개인 판단을 수정하고 공동 법 조항을 만드는지 시험한다.

핵심 가설:

```text
비대칭 정보 → 개인 최초 판단 → 정보 공유 → 추가 증거 → 판단 수정 → 공동 결정
```

## 2. v0.1 범위

- 프로젝트명: **고조선 8조법: 우리 마을의 첫 번째 법**
- 진입 경로: `cooperative-mud/` 허브 → `gojoseon-law/` 에피소드
- 운영: 5개 모둠, 모둠별 실제 인원 3·4·5명, 1인 1아이패드
- 모둠·인원·좌석: 모둠 번호는 교사가 사전 배정하고, 학생이 실제 모둠 인원과 교사가 알려 준 좌석 번호를 선택
- 역할: 농사짓는 사람, 사냥하는 사람, 마을 어른, 어려운 가족을 아는 사람
- 활동: 5분형(사건 2 생략) / 10분형(사건 2 포함)
- 저장: 기기별 `localStorage`에만 저장, 개인정보·학생 ID 미수집
- 공유: 버튼은 네트워크 전송이 아니라 실제 말로 설명했음을 표시하는 로컬 확인

- Firebase·Supabase·서버·로그인·실시간 동기화
- 온라인 채팅·실시간 모둠 투표·교사 대시보드
- 기존 `regular_gojoseon` JSON, MUD 완료 상태, 유물 도감·보상 연동

## 4. 화면 흐름

```text
활동 소개 → 모둠·좌석 선택 → 역할 정보 확인
→ 정보 공유 확인 → 사건 1 최초 판단
→ 추가 증거 → 판단 유지/변경 → (10분형: 사건 2)
→ 모둠 법 조합 → 실제 8조법 비교 → 관찰 항목 확인
```

## 5. 역사 문안 원칙

- “고조선이 8개 조항을 모두 만들었다”라고 단정하지 않고, 『한서』 지리지에 전해지는 범금 8조 중 현재 세 조항이 확인된다고 표현한다.
- 살인·상해·절도와 노비 처벌은 오늘날의 규범으로 권장하지 않고, 당시의 재산·신분 질서를 보여 주는 사료로 분석한다.
- 홍익인간은 법과 직접 등치하지 않고, “내가 만든 법은 누구를 이롭게 하고 누구에게 불리한가?”라는 비교 질문으로 연결한다.
