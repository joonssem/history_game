# 파일럿 4편 16관문 의미 검토표

> 라운드 3 지시서(`docs/handoff/claude_four_track_round3_instruction.md`) §1-1. 자동 검증(계약·D-027·D-030 구조 검사)을 통과한 뒤에도 남을 수 있는 **의미 결함**을 사람이 직접 읽고 확인한 기록이다. Codex red team 감사(`docs/audits/claude_four_track_red_team_audit.md`, RT-01~06)와 D-030 조치(2026-09-14, 커밋 `32f6d82`)가 이미 고친 항목은 "기존 조치"로 표시하고, 이번 검토에서 새로 찾은 것만 "신규"로 표시한다.

## 검토 기준 (라운드 3 §1-1 요약)

- `commit-revise`: 정답 선택지 문장의 **모든 요소**를 `requiredEvidenceIds` 자료가 받치는가.
- `sequence`: 카드가 모두 **날짜/절차로 순서가 확인되는 사건**인가. 의미 질문의 정답이 카드에서 실제로 도출되는가.
- `map-evidence`: 장소·근거·한계 세 정답이 서로 같은 이야기를 하는가. `labels`가 그 편에 맞는가.
- `claim-evidence`: 주장의 요소별 근거 요구(`requiredCategories`/`requiredEvidenceIds`)가 주장 문장보다 과하거나 모자라지 않은가.
- 오답 선택지·피드백이 **정답을 노출하지 않으면서** 왜 부족한지 말하는가.
