## 1. 목적과 판정

오늘 예정된 활동은 **고려의 건국**과 **고려의 문화**다. 협동적 근거 공유와 공동 설명은 유지하되, 로그인·실시간 서버 없이 진행할 교사 진행형 대체 절차를 준비한다.

- 고려 건국 실시간 활동은 2026-09-29 21명 수업에서 일부 학생 입장 실패, 참가자 수 불일치, 전체 진행 차단을 보였다. 복구 코드는 별도 브랜치·Preview에 있지만 Auth0 callback 문제와 4~8대 실기기 리허설이 남아 있어 오늘 기본 경로로 삼지 않는다.
- 고려 문화 협동 활동은 설계 계획과 체크리스트만 있다. 현행 `apps/cooperative-live`에는 문화 협동 시나리오가 없다.
- 현행 `regular_goryeo_culture`는 개인형 MUD다. 이를 근거 탐색에 활용하고 모둠 토론·공동 산출물을 붙이는 것은 가능한 임시 수업 방식이나, 실시간 협동 MUD가 준비된 것처럼 안내하지 않는다.

**당일 권고:** 두 활동 모두 디지털 접속은 선택 자료로만 쓰고, 모둠별 종이 기록지와 교사 진행으로 핵심 협동 흐름을 완성한다. 활동별 15분 배정은 계획값이며 실측값은 아니다. 시간이 부족하면 각 활동의 10분 축약 흐름을 쓴다.

## 2. 공통 운영 원칙

1. 모둠은 3~5명으로 편성하고 기록에는 모둠 번호만 쓴다.
2. 각자 먼저 생각하고, 차례로 근거를 말한 뒤, 모둠이 하나의 답을 만든다.
3. 발표 산출물은 `주장 1개 + 서로 다른 자료/관점의 근거 2개 + 자료의 한계 1개`로 통일한다.
4. 앱이 열리지 않아도 멈추지 않도록 교과서·교사 화면·인쇄 자료를 준비한다.
5. 개인 판단·학생 이름·대화 원문은 수집하지 않는다. 소요 시간·막힌 단계·발화 참여 여부만 익명으로 관찰한다.

## 3. 활동 A — 고려의 건국

기존 [고려 초기 교사용 안내](../../apps/cooperative-live/TEACHING_EARLY_GORYEO.md)의 대체 절차를 사용한다. 교사는 다섯 관점을 짧게 읽거나 카드로 제시한다.

| 관점 | 살필 문제 |
|---|---|
| 신라계 귀족 | 항복한 사람과 기존 지역 질서를 어떻게 대할까? |
| 후백제 지역 농민 | 전쟁 뒤 수취와 생업 부담을 어떻게 덜까? |
| 발해 유민 | 새로 들어온 사람을 어떻게 안전하게 받아들일까? |
| 지방 호족 | 지역 세력과 어떤 협력·책임 약속을 맺을까? |
| 고려 관리 지망생 | 여러 지역에 함께 적용할 기준을 어떻게 세울까? |

3~4인 모둠은 학생에게 관점 하나씩 맡기고 남은 관점은 공통 자료로 둔다. 5인 모둠은 하나씩 맡는다. 한 학생에게 두 관점을 맡기지 않는다.

### 15분 운영

| 시간 | 흐름 | 행동 |
|---:|---|---|
| 0~2분 | 질문·개별 생각 | “새 고려가 서로 다른 사람을 한 나라로 묶으려면 무엇부터 해야 할까?” 각자 정책 하나를 고른다. |
| 2~6분 | 관점 공유 | 한 사람씩 자기 관점의 걱정과 필요한 정책을 말한다. |
| 6~11분 | 모둠 결정 | 정책 2개, 서로 다른 관점의 근거 2개, 자료로 알 수 없는 점 1개를 기록한다. |
| 11~14분 | 공동 설명 | “우리는 ___와 ___를 먼저 하겠다. ___와 ___의 근거를 함께 보면 ___ 때문이다. 다만 ___는 이 자료만으로 알 수 없다.” |
| 14~15분 | 확인 | 발표자가 읽고 교사는 다섯 관점이 고려됐는지 확인한다. |

### 10분 축약

교사가 다섯 관점을 먼저 읽는다. 학생은 1분 동안 개인 선택을 하고, 3분 동안 한 문장씩 공유한다. 모둠은 4분 동안 정책 2개·근거 2개·자료 한계 1개를 정하고, 마지막 2분에 발표한다.

## 4. 활동 B — 고려의 문화와 사람들의 생활

### 당일 자료 사용

- 인터넷·기기가 안정되면 기존 `regular_goryeo_culture`를 개인 자료 탐색에 쓸 수 있다. 시간 감사의 5.7분은 설계 추정치이므로 실제 소요 시간으로 안내하지 않는다.
- 기기 접속이 불안정하면 교사가 기존 MUD 자료와 교과서 자료를 화면에 띄우거나 인쇄한다.
- 생활 모습까지 다루려면 문화재 설명만 사용하지 않는다. 가족·상속·생업 등 생활 자료를 교과서 또는 출처 대조가 끝난 자료에서 한 가지 이상 포함한다. 준비하지 못했으면 생활사까지 다뤘다고 주장하지 말고 문화유산의 제작·사용·목적·자료 한계로 질문 범위를 좁힌다.

### 모둠 질문 렌즈

이는 당일 토론용 역할이며 앱의 비공개 역할 기능이 아니다. 모둠원에게 서로 다른 렌즈를 나눈다.

| 렌즈 | 찾아 말할 것 |
|---|---|
| 만든 사람 | 청자·목판 인쇄 뒤에 어떤 기술과 노동이 있었나? |
| 사용한 사람 | 누가 그 물건이나 기술을 사용·이용할 수 있었나? |
| 신앙·사회 목적 | 불교 문화유산은 어떤 바람·목적·공동 작업과 연결되나? |
| 생활 자료 | 가족·상속·생업·신분 자료가 사람들의 삶에 무엇을 보여 주나? |
| 자료 한계 | 어떤 지역·계층·사람의 경험이 기록에 잘 드러나지 않나? |

3~4인 모둠에서 빠진 렌즈는 공통 질문으로 둔다. 생활 자료가 없으면 추측으로 채우지 말고 “확인할 자료가 더 필요하다”고 표시한다.

### 15분 운영

| 시간 | 흐름 | 행동 |
|---:|---|---|
| 0~2분 | 질문·역할 나누기 | “문화유산은 고려 사람들의 삶을 어디까지 보여 줄까?” 렌즈를 나눈다. |
| 2~7분 | 자료 살피기 | 각자 자료 하나에서 말할 근거를 찾는다. 개인형 MUD를 쓰면 각자 탐색한다. |
| 7~11분 | 근거 공유 | “자료에는 ___라고 보인다. 이것은 ___를 보여 준다.” 형식으로 말한다. |
| 11~14분 | 공동 주장 | 자료 2개를 연결해 기술·신앙·생활 중 추론할 점과 자료 한계를 정한다. |
| 14~15분 | 발표 | “두 자료를 함께 보면 ___를 알 수 있지만, ___는 이 자료만으로 알 수 없다.” |

### 10분 축약

교사가 출처를 확인한 자료 2개를 미리 제시한다. 서로 다른 자료를 맡아 2분간 살피고, 3분간 근거를 공유한다. 3분 동안 주장과 자료 한계를 적고, 마지막 2분에 발표한다.

## 6. 실시간 활동 재개 관문

### 고려 건국 실시간판

1. 복구 브랜치 변경을 기준 브랜치와 배포 환경에 통합하고 Auth0 callback 교사 로그인을 확인한다.
2. 교사 1명과 학생 역할 기기 4~8대로 QR·수동 입장, 탭 종료 후 자리 복구, 학교 Wi-Fi 단절·복귀를 확인한다.
3. 중복 `설명했어요`, 참가자 제외·복원, 모둠별 진행, 초안 revision 재확인, 교사 힌트·심화 이력, QR 확대, 종료 삭제를 확인한다.
4. 전 과정이 8~10분 안에 끝나고 각 학생이 근거를 말로 공유하는지 기록한다.
5. 성인 기기 리허설을 통과한 뒤 학생 3~5명 소규모 재시험을 한다. 막힌 내용은 화면·문장·단계로 특정하고 최소 수정한다.
6. 소규모 재시험과 교사 Go 판정 뒤에만 21명 전체 운영을 다시 연다.

### 고려 문화 실시간판

기존 `P1-COLLAB-GORYEO-RELATIONS-CULTURE` 순서를 따른다. 공통 엔진 복구 게이트, 선행 활동, 역사 자료 출처 검토 뒤 고려 문화 시나리오를 구현한다. 역할 비공개·3/4/5인 편성·공동 답안 근거·자료 한계·세션 삭제 검증, 4~8대 리허설, 학생 소규모 시간·이해도 관찰을 차례로 통과해야 한다.

## 7. 기록과 한계

- 당일 대체안은 실시간 장애를 피하면서 협동적 말하기와 공동 설명을 보존하는 교사 진행 절차다. 실시간 협동 MUD와 동등한 기능이라고 보지 않는다.
- 15분·10분은 수업 편성을 위한 제안값이다. 실제 수업에서 시간을 측정해 `EXPERIMENTS.md`에 기록하기 전에는 완료 시간 기준으로 승격하지 않는다.
- 관찰은 모둠별 완료 시간, 근거 수, 발화 참여 여부, 교사 개입 횟수, 막힌 단계만 익명으로 기록한다.
