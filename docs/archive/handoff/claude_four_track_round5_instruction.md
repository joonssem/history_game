## §0 공통 규칙

1. **기준은 `origin/main`이다.** 라운드 4의 네 브랜치와 R3 수정, Codex T2~T4는 모두 main에 들어갔다.
2. **main 체크아웃(`D:/codexwork/history_game`)은 열지도, 쓰지도 않는다.** Codex가 협동 MUD를 커밋 전 상태로 작업 중이다. **main에 push하지 않는다.** 자기 `feat/*` 브랜치에만 커밋하고, 통합은 기획 세션이 한다.
3. **3단원(일제강점기·광복·6·25·전후)은 수정하지 않는다.** 발견하면 보고만 한다.
4. **판단 대기 항목은 구현하지 않는다.** 대상: 설계 문서 4종, 캔버스 A/B, 근거 목록 기본 펼침, `art_12` 시대, deep-prehistoric 7커밋, 첨성대 해설 문구.
5. **사실 대조 규칙은 라운드 4와 같다.**
   - 공식 출처만 쓴다(우리역사넷, 한국민족문화대백과, 국립중앙박물관, 국가유산포털, UNESCO). 위키백과는 쓰지 않는다.
   - 원문을 실제로 열지 못했으면 "확인 불가"로 적는다. 구체적 수치·단정은 낮추기만 하고 새 단정은 만들지 않는다.
   - IF 단계의 가상 상황 서술은 대조 대상이 아니다.
6. **학생 화면 문구와 출처 메모를 나눈다.** 근거·URL은 `sourceNote`나 `claimScope`에 적고, 학생이 읽는 문장에는 넣지 않는다.
7. **완료 보고에는 다음을 모두 넣는다.**
   - 검증 명령 결과: `04`, `05`, `11`, `13`, `14`
   - 바뀐 파일 목록
   - "확인 불가" 항목
   - 3단원 보고 사항
