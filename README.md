# 🧭 타임머신 역사 탐험대 (History Explorer)
> **초등학교 5학년 사회(역사) 수업 마무리 활동을 위한 체험 및 참여형 인터랙티브 웹 애플리케이션**

본 프로젝트는 초등학교 5학년 2학기 사회(역사) 교과 과정의 차시별 마무리 활동(Wrap-up)으로 활용할 수 있도록 제작된 참여형 게임 웹사이트입니다. 학생들은 타임머신을 타고 과거로 시간 여행을 떠나 역사적 인물과의 대화, 유물 발굴 퍼즐, 스피드 골든벨 퀴즈를 즐기며 학습 내용을 흥미롭게 체득할 수 있습니다.

---

## 🌟 주요 기능 및 학습 콘텐츠

### 1. 🧭 타임머신 역사 스토리 (대화형 비주얼 노벨)
- **고조선 건국 이야기**: 환웅과 웅녀, 비파형 동검의 비밀
- **삼국시대 백제의 예술혼**: 백제 금동대향로 제작 프로젝트
- **조선 세종대왕의 집현전**: 백성을 위한 훈민정음 28자 창제 비화
- 학생의 선택에 따라 반응하는 상호작용 스토리 & 보상 지급

### 2. 🧩 인터랙티브 미니게임존
- **유물 발굴 카드 짝맞추기 (3D Flip)**: 문화재 사진과 명칭을 매칭하여 도감에 등록
- **역사 연표 타임라인 정렬 챌린지**: 뒤섞인 역사적 사건을 시대순으로 정렬

### 3. ⚡ 스피드 골든벨 퀴즈
- 문제당 15초 카운트다운 타이머 & 점수 시스템
- OX 퀴즈 및 4지선다형 핵심 성취기준 문항
- 정답/오답 즉각 피드백 및 친절한 역사 해설

### 4. 📜 나의 역사 도감 & 배지 시스템
- 스토리 클리어 및 미니게임 성공 시 자동으로 문화재 유물과 배지 획득
- 브라우저 `localStorage`를 통해 개인별 학습 기록 영구 보존

### 5. 🧑‍🏫 선생님 수업 정리 모드 & 편의 기능
- 수업 종료 5분 전 핵심 성취기준 한눈에 보기
- 전자칠판/빔프로젝터용 **전체화면(Fullscreen)** 모드
- 무외부의존성 **Web Audio Synth** 사운드 효과음 (음소거 토글 가능)

## 🚀 GitHub Pages 3단계 배포 가이드

별도의 Node.js 설치나 빌드 과정 없이, 순수 정적 웹(Vanilla HTML5/CSS3/JS)으로 제작되어 GitHub 저장소에 Push하기만 하면 1분 만에 전 세계에 무료 배포됩니다.

### 1단계: GitHub 저장소 생성 및 푸시
```bash
git init
git add .
git commit -m "feat: 초등 5학년 역사 인터랙티브 게임 웹사이트 구축"
git branch -M main
git remote add origin https://github.com/joonssem/history_game.git
git push -u origin main
```

### 2단계: GitHub Pages 활성화
1. GitHub 저장소의 **[Settings]** 탭으로 이동합니다.
2. 좌측 메뉴에서 **[Pages]** 를 클릭합니다.
3. **Branch** 설정을 `main` / `/(root)` 로 선택 후 **[Save]** 를 누릅니다.

### 3단계: 배포 완료 및 수업 활용
약 1~2분 후 제공되는 URL(예: `https://{사용자_아이디}.github.io/{저장소_이름}/`)로 학생들과 태블릿, 크롬북, PC에서 즉시 접속하여 수업을 진행할 수 있습니다.
