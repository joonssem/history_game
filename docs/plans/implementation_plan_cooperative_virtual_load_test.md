# 실시간 협동 MUD 가상 21명 회귀 테스트 계획

- 작성일: 2026-09-09
- 작업: TASK-20260909-03
- 상태: `completed`
- 대상: `apps/cooperative-live`

## 목적

실제 학생 데이터를 사용하지 않고 교사 1명과 가상 학생 21명의 입장·편성·진행·종료 삭제 흐름을 자동 검증한다. 운영 전용 우회 API는 추가하지 않는다.

## 구현 범위

1. 공식 `convex-test` 환경에서 현재 Convex 스키마와 함수를 실행한다.
2. 교사 인증 주체로 세션을 만들고 QR 입장키를 이용해 가상 학생 21명을 동시에 입장시킨다.
3. 중복 없는 호 선택, 3~5명 균형 모둠 편성, 학생 진행과 교사 개입 반영을 검증한다.
4. 세션 종료 뒤 세션·학생·모둠·개입·연결된 입장 시도 행이 모두 삭제되는지 확인한다.
5. 기존 순수 함수 테스트와 함께 한 명령으로 실행되도록 검증 스크립트를 연결한다.

## 제외 범위

- 실제 학생·실명·학번·기기 식별자 사용
- 학교 Wi-Fi, 물리 아이패드, 카메라 QR 인식 실측
- Convex 공급자 로그·백업 보존기간 확인
- 콘텐츠·시나리오 문장 변경

## 완료 기준

- 21명 입장 결과가 모두 성공하고 정원 24명을 넘지 않는다.
- 편성 결과가 3~5명 균형 모둠이며 역할·호가 중복되지 않는다.
- 종료 뒤 관련 애플리케이션 테이블에 해당 세션 데이터가 남지 않는다.
- lint, TypeScript, 전체 테스트, Next.js production build가 통과한다.
