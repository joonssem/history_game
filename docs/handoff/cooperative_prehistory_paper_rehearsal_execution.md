# 선사 시대 협동 MUD 막 1 종이 리허설 실행표

TASK-20260904-01 | 선사 시대 협동 MUD 막 1 종이 리허설 착수 | 담당: 실행·통합 에이전트 | 상태: `DEFERRED`

상태: `deferred` / 고조선 8조법 아이패드 협동 MUD 검증으로 재개 시점 보류

## 1. 이번 리허설의 범위

- 대상: 막 1 `강가의 흔적: 구석기`
- 방식: 종이 역할 카드, 공동 기록지, 교사 진행
- 모둠: 4인 기준, 3인·5인 변형 가능
- 목표 시간: 교사 안내 포함 약 20분
- 이번 단계에 포함하지 않음: 막 2·3, 웹앱 코드, 서버, 계정, 점수, 녹음·촬영, 기존 MUD·도감 연동

카드와 문안은 [`cooperative_prehistory_content_draft.md`](../plans/cooperative_prehistory_content_draft.md) §9~§12를 원문으로 사용한다. 이 실행표는 내용을 복제하지 않고 인쇄·진행·관찰 순서만 정의한다.

## 2. 사전 준비

모둠마다 다음을 준비한다.

- 공통 상황 카드 1장
- 역할 카드 A~D 각 1장: 먹거리 조사관, 도구 관찰관, 터전 기록관, 증거 점검관
- 5인 모둠이면 근거 기록관 카드 E 1장 추가
- 공동 기록지 1장
- 필기구 1세트

역할 카드는 봉투 또는 뒤집은 상태로 분리한다. 학생은 자신의 카드만 먼저 읽고, 역할별 설명이 시작될 때까지 다른 카드 내용을 보지 않는다. 3인 모둠은 먹거리 조사관과 터전 기록관을 한 학생이 겸임한다.

## 3. 진행 순서 — 20분 안팎

| 시간 | 교사·학생 활동 | 교사 관찰 포인트 |
|---:|---|---|
| 0~2분 | 공통 상황 카드와 공동 질문을 함께 읽는다 | 질문을 정답 맞히기로 먼저 바꾸지 않는가 |
| 2~5분 | 각자 역할 카드를 조용히 읽고 `자료`와 `모르는 점`을 표시한다 | 학생이 자기 카드의 핵심 근거를 파악하는가 |
| 5~11분 | 역할별로 30~45초씩 설명한다. 친구는 카드 내용을 대신 읽지 않고 질문한다 | 네 역할의 단서가 실제 발언되는가 |
| 11~16분 | 모둠 공동 기록지를 작성한다 | 사실·해석·알 수 없는 점이 구분되는가 |
| 16~18분 | 사용한 근거를 두 가지 이상 표시하고 최종 전시 문장을 다듬는다 | 한 학생이 문장을 독점하지 않는가 |
| 18~20분 | 공동 선택지 1~3 중 하나를 고르고 근거를 말한다 | 정답보다 근거 연결과 단정 중지가 드러나는가 |

교사는 카드의 정답 문장을 먼저 읽어 주지 않는다. 필요한 경우 [`cooperative_prehistory_content_draft.md`](../plans/cooperative_prehistory_content_draft.md) §11의 질문만 사용한다.

## 4. 관찰 기록지

모둠 이름 대신 상징 또는 번호만 사용한다. 학생 이름·학번·자유 대화 원문은 기록하지 않는다.

### 핵심 판정

- [ ] 4개 역할의 `모둠에 꼭 말할 문장`이 모두 실제로 발언되었다.
- [ ] 학생들이 사실과 해석을 한 번 이상 구분했다.
- [ ] 공동 문장이 서로 다른 자료를 두 가지 이상 사용했다.
- [ ] `자료만으로는 알 수 없다`는 표현이 실패가 아닌 신중한 설명으로 받아들여졌다.

### 운영 신호

- 실제 소요 시간: ______분
- 교사가 개입한 횟수: ______회
- 특정 학생의 발언 독점: 없음 / 약간 / 큼
- 다른 역할 카드 공개 또는 대신 읽기: 없음 / 있음
- 공동 선택 전에 언급된 근거 수: ______개
- 학생이 사용한 표현 또는 반응 1개(이름 없이): __________________________

## 5. 판정과 다음 단계

### 유지

핵심 판정 4개가 모두 확인되고, 활동이 약 20분 안에 끝나며, 한 학생의 정보 독점 없이 역할별 설명이 이루어지면 막 1 문안을 유지한다. 같은 문안으로 다른 모둠 1개 이상을 추가 관찰한다.

### 보완

핵심 판정 중 1~2개가 빠지거나 교사 질문이 반복적으로 필요하면, 학생 반응과 막힌 지점을 기록하고 카드 문구·진행 순서를 최소 수정한다. 역사적 사실을 새로 추가하지 않는다.

### 보류

역할 분리가 유지되지 않거나, 공동 선택이 근거 토의 없이 이루어지거나, 20분을 크게 초과하면 막 2·3 운영과 웹 구현을 보류한다. 실패 원인을 문서화한 뒤 막 1을 다시 시험한다.

막 1 리허설이 `유지` 판정을 받은 뒤에만 막 2·3의 역사 사실을 기존 `regular_neolithic.json`, `regular_bronze_age.json`, `regular_gojoseon.json` 및 공식 자료와 재대조하고, 다음 운영 범위를 결정한다.
