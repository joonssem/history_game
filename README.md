# 🧭 초등 5학년 역사 인터랙티브 MUD 포털 (History Explorer MUD)

> **초등학교 5학년 2학기 사회(역사) 전 단원(48차시) 교수·학습 과정안 기반 텍스트 MUD & 캔버스 인터랙티브 교육 포털**  
> 🌐 **실시간 웹사이트:** [https://joonssem.github.io/history_game/](https://joonssem.github.io/history_game/)

---

## 📖 프로젝트 개요

본 프로젝트는 초등학교 5학년 2학기 사회(역사) 교과서 및 실제 **교수·학습 과정안(지도안)**을 100% 반영하여, 학생들이 주도적으로 역사의 주역이 되어 의사결정을 내리고 시뮬레이션을 조작하는 **체험·참여형 MUD(Multi-User Dungeon/Visual Text Novel) 교육 플랫폼**입니다.

- **대상 학년**: 초등학교 5~6학년
- **기반 교육과정**: 2022/2015 개정 초등 5학년 2학기 사회 (총 3개 단원, 48개 차시)
- **핵심 목표**: 역사적 사건의 단순 암기를 넘어, 역사적 상황 속 '결단의 순간'을 체험하며 역사적 사고력과 문제 해결력 신장

## 🕹️ 탑재된 MUD 시뮬레이터 & 교육 콘텐츠

### 🏛️ 1단원. 옛 사람들의 삶과 문화
1. **2차시: 🪨 [구석기 생존 MUD]** (연천 전곡리의 아슐리안형 주먹도끼와 동굴 불 피우기)
2. **3차시: 🏺 [신석기 빗살무늬 MUD]** (암사동 뾰족 그릇 빚기와 모래밭 정착, 가락바퀴 직조)
3. **4~5차시: 🗿 [청동기 고인돌 MUD]** (벼농사 잉여 생산과 군장의 탄생, 고인돌 거석 운반 과학)
4. **6차시: 📜 [고조선 8조법 MUD]** (단군왕검 건국과 생명·재산 존중 8조법 법정 시뮬레이터)
5. **7~8차시: ⚔️ [삼국 한강 쟁탈전 MUD]** (백제 근초고왕 ➔ 고구려 장수왕 ➔ 신라 진흥왕의 한강 유역 쟁탈과 가야 연맹)
6. **9~10차시: 🎨 [고분 벽화 탐정 MUD]** (수산리 벽화 복식 탐구, 불교 공인, 가야 철제 판갑옷과 고구려 맥적)
7. **13차시: 👑 [왕건의 고려 건국 MUD]** (궁예 축출, 발해 유민 포용, 훈요 10조 선포)
8. **14차시: 📜 [고려 사회 탐정 MUD]** (광종의 과거제와 홍패, 손변의 남매 균등 상속 재판, 부석사 배흘림기둥)
9. **20차시: ⚡ [1단원 총정리 스피드 골든벨 & 방탈출 암호]**

### 🏯 2단원. 사회의 새로운 변화와 오늘날의 우리
1. **2~3차시: 🏛️ [한양 도읍 설계 MUD]** (정도전의 유교 4대문 명명과 근정전 박석의 과학적 원리)
2. **7차시: ⚔️ [명량 해전 MUD]** (13척 vs 133척, 판옥선 천자총통 포격 조작 & 울돌목 조류 역전 조작)
3. **8차시: 💰 [조선 후기 경제 MUD]** (모내기법(이앙법) 보급, 상품 작물 재배, 상평통보 엽전 유통 & 5일장)
4. **9차시: 🌍 [실학자 탐구 MUD]** (둥근 지구의/천리경 수용, 정약용 실사구시, 동학 인내천 평등 사상)
5. **14차시: ⚡ [2단원 총정리 스피드 골든벨 & 방탈출 암호]**

## 🛠️ 기술 스택 및 구조

* **Frontend**: Pure Vanilla HTML5, CSS3, ES6+ JavaScript
* **Graphics**: HTML5 `<canvas>` 기반 커스텀 2D 시뮬레이션 엔진 (조류 역전, 엽전 경제, 거석 운반, 빗살무늬 빚기)
* **Audio**: 무외부의존성 브라우저 내장 **Web Audio API Synth** 기반 인터랙티브 효과음
* **Data Storage**: `localStorage` 기반 개인별 퀘스트 및 탐구 일기 저장
* **Data Structure**: `data/history_curriculum_48_lessons.json` (48개 전 차시 메타데이터 구축)
