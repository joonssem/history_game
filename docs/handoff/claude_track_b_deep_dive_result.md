- **오답 선택지 어조 정상화**: 원래 6번("상업은 천한 것이니 시장을 모두 폐쇄") · 7번("억지로 매질하여")은 정답과 대비해 지나치게 극단적인 어조라 문장 톤만으로 정답을 추측할 수 있었다. 각각 "특산물·물물교환으로 되돌린다" / "품삯 없이 부역으로 동원한다"처럼 정책적으로 그럴듯한 문장으로 다듬었다.
- **단서 선언은 완료했지만, 선택지 자체가 단서를 직접 인용하도록 다시 쓰지는 않았다.** 즉 "단서 A·C를 근거로 ~한다" 형태로의 전환은 이번 범위에 포함하지 않았다(§9 다음 규칙 참고) — 지시서 요구사항 5번("위치·길이·구체성만으로 정답 추측 불가")은 톤 완화로 부분 충족했으나, 근거 인용형 전환만큼 강한 보장은 아니다.
- 나머지 프로젝트 전역 길이 편향(예: `regular_goryeo_society:3` 델타 18.0)은 이 파일럿의 범위 밖이며 `choice_bias_audit.md`/`implementation_plan_choice_quality_batch.md`가 이미 별도로 추적 중이다.

## 8. 수정하지 않은 문제와 공용 엔진 요청 사항

- **공용 엔진 요청 없음.** 이번 파일럿은 기존 `hotspot-discovery`/`required`/`completion` 계약과 기존 scene 팔레트만으로 완결되어, `js/mudEngine.js`·`js/mudSimulators.js` 변경 요청 사항이 없다.

- 선택지가 단서를 직접 인용하도록 다시 쓰는 작업(§9의 규칙 1)은 이번 범위에 포함하지 않았다.
- `deep_joseon` 외 나머지 프로젝트 전역 선택지 길이 편향은 손대지 않았다(`choice_bias_audit.md` 소관).
- 실제 학생 대상 플레이 시간 실측은 하지 않았다(교실 실험 필요, §4 참고).
