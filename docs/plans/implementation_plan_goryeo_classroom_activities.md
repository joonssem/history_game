## 1. 승인된 범위

사용자는 “알겠어. 일단 만들자. 수업은 나중에 할게.”라고 승인했다. 이번 묶음은 다음 두 활동만 다룬다.

1. **고려의 건국:** 2026-09-29 수업에서 발견된 참가자 복구·제외·모둠별 진행 문제를 해결한 `feat/cooperative-classroom-recovery-p0` 변경을 구현 기준으로 사용한다.
2. **고려의 문화:** 문화유산과 생활 기록을 서로 다른 관점으로 나누고, 역할 근거 두 개와 자료 한계를 결합하는 `goryeo-culture-life` v1 협동 시나리오를 추가한다.

이번 범위에서 **고려와 주변 나라들의 관계 활동은 만들지 않는다.** 기존 15~16차시 구현 계획은 별도 백로그로 보존한다. 사용자 승인은 코드·콘텐츠 제작을 허용하며 배포, 운영 환경 변경, 실제 수업 사용을 승인한 것은 아니다.

## 2. 문화 활동 설계

**핵심 질문:** 고려의 문화유산과 기록은 고려 사람들의 삶과 생각을 어디까지 보여 줄까?

역할 자료는 5학년이 읽기 쉬운 짧은 문장으로 구성하고, 사실과 추론 및 자료의 한계를 분리한다.

| 관점 | 핵심 자료 | 일반화 방지 |
|---|---|---|
| 청자 공방 장인 | 비색과 상감 기법 | 청자 한 점만으로 사용 계층을 단정하지 않는다. |
| 가족 기록 살피는 사람 | 염경애 묘지명의 한 가족 상속 사례 | 한 가족 기록을 모든 여성·가족에게 넓히지 않는다. |
| 대장경 목판 작업자 | 1237~1248년 목판 제작, 몽골 침입기 불교 신앙 | 제작 참여자의 생활은 별도 자료 없이 단정하지 않는다. |
| 금속 활자 인쇄 기술자 | 1377년 직지 | 현존 자료를 기술의 보편적 보급으로 해석하지 않는다. |
| 자료 한계 검토자 | 유물·기록의 범위 | 빠진 지역·계층·생활을 확인한다. |

3인 모둠에는 빠진 직지 관점을 공통 자료로 제공하고, 4인 모둠은 청자·가족 기록·대장경·직지를 맡는다. 5인 모둠은 자료 한계 역할을 더한다.

공동 산출물은 문화 주제 두 가지, 서로 다른 역할의 근거 두 개, 자료 한계 하나, 자료를 함께 읽는 이유 하나다. 최종 답안은 한 유물 설명이나 역할 한 사람의 자료만으로 완성할 수 없어야 한다.

## 3. 구현 지점

- `apps/cooperative-live/shared/scenario.ts`: 공개 메타데이터, 역할명, 3·4·5인 구성
- `apps/cooperative-live/convex/scenarios.ts`: 역할별 비공개 사실·관심·근거, 공동 질문, 공통 자료, 교사 개입, 출처
- 시나리오 레지스트리·가상 학급 검사: 공개/비공개 자료 경계와 공통 자료 제공 확인
- `apps/cooperative-live/TEACHING_GORYEO_CULTURE.md`: 10분 목표 흐름, 교사 발문, 리허설 전제, 출처와 해석 범위
- 교사 화면은 `PUBLIC_SCENARIOS` 목록을 읽으므로 별도 화면 분기 없이 새 활동을 선택할 수 있어야 한다.

고려 건국 복구 동작은 기준 브랜치의 코드를 새로 복제하지 않고, 그 브랜치를 부모로 하는 격리 worktree에서 통합 회귀한다.

## 4. 자동 검증과 완료 기준

`apps/cooperative-live`에서 `npm run check`를 실행한다. 공개 역할 구성, 시나리오 레지스트리, Convex 가상 모둠 검사는 최소 다음을 확인한다.

- 두려는 시나리오 ID와 version이 공개 목록·서버 목록에서 일치한다.
- 고려 문화 3·4·5인 모둠에 역할 중복이 없고, 3인에게 빠진 인쇄 관점의 공통 자료가 나타난다.
- 학생은 자기 역할 본문만 받고, 공유 단계 이후 다른 역할은 허용된 근거 요약만 본다.
- 서로 다른 역할의 근거 두 개와 자료 한계를 넣어 공동 초안을 만들 수 있다.
- 기존 21명 수업 복구, 고조선, 고려 건국, 조선 후기 회귀가 유지된다.

## 5. 교실 사용을 위한 후속 관문

코드와 자동 검증이 완료되어도 교실 사용은 미승인 상태다. 수업에 쓰기 전에 별도로 다음을 통과한다.

1. Auth0 callback·교사 로그인 및 실제 사용할 Vercel·Convex 환경을 확인한다.
2. 실제 교사 1명과 성인·교사 역할 기기 4~8대로 QR·수동 입장, 역할 비공개, 복구, 모둠별 진행, 재확인, 도움 요청, 세션 종료 삭제를 검증한다.
3. 개인정보 운영 근거와 배포 환경 설정의 일치를 확인한다.
4. 소규모 학생 파일럿에서 읽기 난이도·완료 시간·참여를 익명 관찰한 뒤 교사가 Go/No-go를 결정한다.

기기·인증 문제를 해결하지 못하면 고려 건국은 교사 진행형 대체안, 고려 문화는 교사 제공 자료와 종이 기록지로 진행한다. 활동별 운영 기록은 `EXPERIMENTS.md`에 남긴다.
