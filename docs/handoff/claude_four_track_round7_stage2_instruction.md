# 4트랙 라운드 7 — 2단계 지시서: 확정 문장 만들기

> 작성: 2026-09-16, 기획 세션(Opus). 기준: `origin/main` 최신(1단계 통합 뒤). D-034 확정값과 라운드 7 §0 규칙은 그대로 유지한다.

## 순서

- **2-가(지금, 세 창 동시)**
  - 관문 설계실: 역할 카드 확정
  - 대조실: 확인 불가 항목 해소, 품팔이 카드 대조
  - 조작대: 글 길이 검사
- **2-나(관문 설계실 완료·통합 뒤)**
  - 연결 공방: 확정 문장을 JSON에 옮김. **지금은 시작하지 않는다.**

## §1 관문 설계실 — 대조실 수정 요청 반영, 역할 카드 확정

- **파일**: `docs/handoff/claude_joseon_late_role_cards.md`만 고친다.
- `docs/audits/joseon_late_source_review.md`의 `ROLE_CARD_REVIEW` 절 판정을 문장마다 반영한다.
  - **범위 초과**: 대조실 제안 문장으로 고친다. 예를 들어 농민 #2 "혼자 힘으로"는 원문이 농번기에 고용 노동을 함께 썼다고 하므로 고친다.
  - **확인 불가**: 문장을 빼거나, 원문이 확인된 범위의 더 일반적인 문장으로 낮춘다. 대조실이 2-가에서 확인해 오면 되살릴 수 있게, 뺀 문장은 문서 끝 "보류 문장"에 남긴다.
  - 대동법·공인 서술: "곧 전국에 퍼졌다" 류의 시기 오류가 없게 한다. 1608년 경기 시행, 1708년 전국 시행 완료, 100년에 걸친 과정이다.
- 품팔이 카드는 대조실의 품팔이 근거 절을 따라 **"몰락 농민 중 일부"** 범위로 확정한다.
- 카드마다 `privateInfo`는 3~5문장이다. 한 문장은 **40자 안팎**을 목표로 한다(아이패드 가독성, 조작대가 검사한다).
- 완료되면 문서 첫머리의 상태를 "확정(2단계)"으로 바꾼다.

## §2 대조실 — 확인 불가 해소와 품팔이 카드 대조

- **파일**: `docs/audits/joseon_late_source_review.md`만 고친다.
- `ROLE_CARD_REVIEW` 절의 확인 불가 항목을 원문으로 확인한다. 농민 #3 이모작, 보부상 #2 값 변동, 수공업자 #3·#4, 기록관 #3 등이다.
  - 확인되면 판정을 "맞음"으로 바꾸고 근거 URL을 적는다.
  - 끝내 원문을 찾지 못하면 "확인 불가 확정"으로 두고, 관문 설계실이 문장을 뺀 것을 유지한다.
- 관문 설계실이 1단계에서 쓴 **품팔이(`laborer`) 카드** 문장을 같은 표 형식으로 대조한다.
- `ev6_mining` 짧은 라벨의 대안 문장을 제안한다. 연(鉛)·은 생산지 대상의 설점수세제라는 범위를 반영한다. 연결 공방이 2-나에서 쓴다.

## §3 조작대 — 글 길이·가독성 검사

- **파일**: `scripts/15_validate_cooperative_packet.js`, `walkthrough.md`
- 일정표 10/5~10/9 항목("텍스트 길이·아이패드 가독성")을 미리 기계 검사로 만든다.
  - `privateInfo`: 문장 수 3~5, 문장당 글자 수(권장 40, 경고 60 초과)
  - `sharePrompt`·`interest`·`firstJudgment.prompt`: 한 문장, 80자 이하 경고
  - `evidenceOptions[].shortLabel`: 30자 이하 경고
  - `limitOptions[].text`: 60자 이하 경고
- 역할 카드 문서(`claude_joseon_late_role_cards.md`)의 `privateInfo` 목록에도 같은 길이 검사를 적용하는 `--cards` 옵션을 둔다. 관문 설계실이 2-가에서 바로 쓸 수 있게 한다.
- 기준값은 제안값이다. 보고서에 "수업 리허설(10/12~16)에서 조정"이라고 적는다.

## §4 연결 공방 — 2-나 (기획 세션이 시작을 알린 뒤)

- 확정된 역할 카드의 `privateInfo`·`sharePrompt`·`interest`를 패킷 JSON 자리표시자에 옮긴다.
- 대조실 제안으로 `ev6_mining` 등 범위 초과 라벨을 고친다.
- `node scripts/15_validate_cooperative_packet.js --final`이 자리표시자 0곳으로 통과해야 한다.
