## 2. P2 — 판단 하나로 진행할 수 있는 개선

- [ ] **2-1. 포털 첫 화면에 "이어서 하기" 카드 추가** (구조 개편 ①, 첫 단계)
  - 판단 필요: 카드 위치(헤더 아래, 과제 안내 상자 대체 여부)
  - 완료 기준: 연대표 띠의 '지금' 칸(또는 첫 미완료 편)을 큰 카드로 보여 주고, 누르면 바로 그 MUD가 열린다. 첫 방문 학생에게는 1번 편이 나온다. 기존 탭·카드는 그대로다.
  - 관련: `js/lessonTrack.js`, `js/app.js`, `index.html`

- [ ] **2-2. 포털에 구역 이동 버튼 달기**(차시 탐험 · 더 탐구하기 · 모둠 활동)
  - 완료 기준: 첫 화면에서 한 번 눌러 확장 활동·비교·협동으로 이동한다. 기존 구획 순서는 바꾸지 않는다.

- [ ] **2-3. 유물·유적 비교 활동의 포털 입구 만들기**
  - 완료 기준: 포털에서 비교 활동이 있다는 것과 해금 조건(예: "유물 2개를 모으면 열려요")을 볼 수 있다. 해금된 페어가 있으면 바로 시작한다.
  - 관련: `js/artifactComparison.js`, `index.html`

- [ ] **2-4. 연대기(로드맵)의 오답 분기·[실패] 표시 정리** (A6)
  - 판단 필요: (가) 방문한 단계만 보이기 / (나) 모두 보이되 [실패] → "다시 생각하기"
  - 완료 기준: 정답 경로가 처음부터 드러나지 않고, 학생 화면에 [실패] 문구가 없다.
  - 관련: `js/mudEngine.js`(`renderRoadmap`·`updateRoadmap`), 로드맵 라벨 데이터

- [ ] **2-5. 학생에게 보이는 개발 용어 바꾸기** (C)
  - 판단 필요: 대체어 확정
    - [ ] "MUD" → "역사 탐험"(제목 접두어 "MUD " 제거 포함)
    - [ ] "Deep-dive MUD (30분+ 롤플레이)" → "대단원 도전"
    - [ ] "SIMULATOR" 배지 → "탐구 도구"
    - [ ] 협동 허브 "DB 없이 실행" → 교사 안내로 이동
  - 완료 기준: 학생 화면(포털·MUD·완료·도감·협동 허브)에 위 용어가 남지 않는다. 파일명·`mudId`는 그대로다.

- [ ] **2-6. 단원 이름 한 가지로 통일**
  - 판단 필요: 기준 데이터(`curriculum_standards_2022.json`의 `unitTitle` 제안)
  - 완료 기준: 포털 탭·README 단원 표 제목·완료 화면이 같은 이름을 쓴다(현재 1단원 탭과 README 세 단원이 데이터와 다르다).

- [ ] **2-7. 하단 버전 표시를 실제 배포와 맞추기** (A7)
  - 완료 기준: 배포할 때마다 바뀌는 값(예: `mudEngine.js` 캐시버스터 날짜)이 표시된다.

## 3. P3 — 수업 관찰 뒤에 할 구조 개편

착수 조건: 아래 4장 관찰 질문의 결과가 기록된 뒤. 결과에 따라 순서를 바꾸거나 뺀다.

- [!] **3-1. 연대표 띠를 주 내비게이션으로, 단원 탭을 필터로 합치기**
  - 완료 기준: 띠 칸을 누르면 해당 차시 카드로 이동하거나 MUD가 열린다. 탭은 띠·카드를 함께 거른다. 두 탐색 도구가 따로 움직이지 않는다.
- [!] **3-2. 차시 카드 정리**
  - [ ] MUD가 있는 차시만 기본으로 표시하고, 교과서 전용 차시는 접기
  - [ ] 교과서 쪽수·핵심 개념은 "교사 보기"로 접기
  - [ ] 나뉜 차시(예: 4~5차시 1/2·2/2)의 같은 MUD 버튼을 카드 하나로 합치기

- [!] **3-3. Deep-dive를 단원 끝 "대단원 도전" 카드로 모으기**
- [!] **3-4. "더 탐구하기" 구역 만들기**: 비교·타임머신 스토리·미니게임·골든벨을 한 구역 카드로
- [!] **3-5. 협동 MUD 배너를 "모둠 활동" 구역으로 옮기기**(탭 위 배너 제거)

  - 판단 필요: (가) 도감·확장 활동·딥다이브를 한지 팔레트로 통일 / (나) "보관소=어두운 테마"처럼 역할별 규칙을 문서화
  - 완료 기준: 색을 `css/style.css` 변수로 모으고, 모든 어두운 구역의 글자 명암비가 4.5:1 이상이다.
- [!] **3-7. P3 묶음 회귀 확인** — 1-6 항목 + 교사 1인 수업 흐름 리허설(오늘 차시 찾기 → MUD → 완료 → 다음 활동)
