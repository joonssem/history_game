## 5. 오늘 배운 것

- **문구 수정은 한 단계의 모든 칸을 함께 본다.** 이야기·선택지·단서·장소·안내·피드백·재시도 버튼·로드맵 라벨·헤더가 한 묶음이다. 선택지 `feedback`처럼 화면에 안 보이는 칸도 데이터 품질 대상이다.
- **자동 검사는 모양만 본다. 문구를 고치면 브라우저로 확인한다.** 용어 말풍선 깨짐은 데이터 검사로는 절대 나오지 않았다.
- **조사용 검색식을 믿지 말고 검사를 실행해 확인한다.** Deep-dive의 `N-fail` id를 검색식이 놓쳤고, 검사 실행이 잡았다.
- **같은 폴더를 Codex와 함께 쓸 때는 worktree에서 작업하고, 상대가 커밋하지 않은 파일(BACKLOG 등)은 push하지 않는다.** 오늘은 이 방식으로 충돌 없이 진행했다.
- **CRLF 파일을 스크립트로 고칠 때는 줄바꿈을 섞지 않는다.** 섞이면 Git 자동 변환이 동작하지 않아 전체 줄이 바뀐 것처럼 보인다.
- **자동 모드 권한 확인이 한동안 응답하지 않았다.** 일반 권한 모드로 바꿔 진행했다.
