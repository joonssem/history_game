### 확인 방식에 관한 정직한 표시 (2단계 갱신)

지시서 2-§2가 지목한 **핵심 4건은 이번 2단계에서 WebFetch로 원문을 직접 열어 확인**했다 — 통일신라 935년(1단계에 이미 WebFetch 완료, 2단계에 재검토해도 동일), 발해 698년, 일제강점기 1910~1945, 신석기 기원전 8000년경(한반도 특정 서술로 재확인). 이 중 **신석기는 처음 연 페이지가 세계사적 신석기 혁명 얘기였고 한반도 특정 서술이 아니어서, 두 번째 페이지를 더 열어서야 한반도 맥락의 같은 문장을 확인했다** — 검색 스니펫만 믿었으면 놓쳤을 오독이다.

나머지 항목(신석기·발해의 세부, 청동기, 고조선, 삼국, 고려, 조선 전기/후기, 개항기, 광복)은 1단계와 마찬가지로 **WebSearch 결과 종합**(우리역사넷 도메인만 채택)으로 남겨 뒀다 — "검색 확인"이라고 표에 그대로 적었다. 더 엄밀한 검증이 필요하면(특히 개항기 종료 연도, 청동기 종료 연도, 고조선 멸망) 다음 라운드에 개별 URL을 WebFetch로 재확인할 것을 제안한다.

## 2. 시대 경계가 겹치거나 비는 곳

### 2-1. 발해 ↔ 통일신라 — 실제로 228년간 겹친다 (핵심 판단 필요)

- **발해(698~926)와 통일신라(676~935)는 동시에 존재했다.** 이 겹침 자체가 "남북국시대"라는 명칭의 근거다 — 발해(북)와 통일신라(남)가 같은 시기 한반도·만주에 나란히 있었다는 것이 표준 서술이다.
- 띠는 순서상 나열되는 구조라, 두 시대를 "통일신라 → 발해" 순서로 나란히 배치하면 **마치 발해가 통일신라 다음에 시작한 것처럼 왜곡**된다. 실제로는 발해가 통일신라 건국(676) 22년 뒤에 시작해서, 통일신라가 끝나기(935) 9년 전에 먼저 멸망했다(926) — 발해가 통일신라 "안에" 통째로 들어가는 관계에 더 가깝다.
- **판단 제안**: 띠 자체는 (`data/mud/_index.json` 순서를 따르는) **차시 진행 순서를 보여주는 것이지, 축척이 정확한 연표가 아니다** — 이 활동의 목적(§0-2)과 맞다. 그러니 순서 자체는 실제 MUD 배치 순서(1단원 11차시 통일신라, 12차시 발해)를 그대로 따르되, **연결 공방·조작대가 화면에 두 칸을 표시할 때 "발해는 통일신라와 같은 시기"라는 짧은 안내를 eraLabel 옆에 덧붙이는 방안**을 제안한다(예: 발해 칸에 작은 글씨로 "(통일신라와 같은 시대)"). 이건 UI 문제라 대조실이 직접 만들지 않고, `docs/plans/implementation_plan_lesson_track_ui.md`(연결 공방)에 참고하도록 이 절을 남긴다.
- **하지 말 것**: 두 시대의 연대(`eraRange`) 자체를 겹치지 않게 억지로 쪼개거나 조정하지 않는다 — 실제로 겹치는 게 맞는 사실이라 왜곡하면 안 된다.

### 2-2. 청동기 ↔ 고조선 — 개념적으로 겹친다

- 고조선은 청동기 문화를 바탕으로 성립한 나라다 — "청동기 시대"라는 **기술 수준에 따른 시대 구분**과 "고조선"이라는 **국가 단위 구분**은 서로 다른 분류축이라 자연히 겹친다(신석기 다음이 청동기, 청동기 다음이 고조선 순서로 딱 떨어지는 게 아니다).
- 우리 프로젝트의 `art_3`(고창 탁자식 고인돌, era: "청동기 시대")·`art_4`(비파형 동검, era: "고조선")도 사실 비슷한 시기(기원전 2000~1500년경 이후~기원전 108년까지)를 배경으로 한다.
- **판단 제안**: 이건 발해·통일신라만큼 극적인 왜곡은 아니다(청동기가 고조선보다 넓은 개념이라 "청동기 → 고조선" 순서 배치가 아주 틀린 건 아님) — 별도 배지 없이 그대로 순차 배치해도 큰 문제는 없다고 본다. 다만 관문 설계실이 `eraLabel`을 정할 때 "청동기 시대"와 "고조선"을 **서로 다른 이야기인 것처럼 완전히 분리**하지 말고, "고조선도 청동기 문화 위에서 시작했다"는 걸 짧게 언급할 여지를 열어 두면 좋다(필수 아님).

### 2-3. 삼국 ↔ 통일신라 — 자연스러운 순차, 문제 없음

- 삼국시대(~668)가 끝나고 통일신라(676~)가 시작하는 것은 순차적이라 겹침 문제가 없다. 다만 668년(고구려 멸망)과 676년(나당전쟁 승리로 실질적 통일) 사이 **8년의 공백**이 있다 — 이 기간은 신라가 당의 세력을 한반도에서 몰아내는 전쟁기라 "삼국시대도 통일신라도 아닌" 애매한 구간이다. 띠에서 이 8년을 굳이 표시할 필요는 없다고 본다(5학년 수준에 과한 정보) — 다만 두 eraRange를 이어 붙일 때 "668~676"처럼 억지로 채우지 말고 각자의 실제 경계(~668, 676~)를 그대로 쓰면 자동으로 이 공백이 생기는데, 그건 괜찮다(왜곡이 아니라 사실).
