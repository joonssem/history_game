# Claude Code 작업 지시서 — IF 최종 승인·세종 중복 키 확인

## 목적

사용자 최종 검토를 위해 IF 스테이지 6개와 `regular_sejong` simulator 중복 키 문제를 간단한 승인 자료로 정리한다.

이번 작업은 **검증·보고만 수행하며, 승인 전에는 파일을 수정하지 않는다.**

## 1. IF 스테이지 최종 확인

대상:

- `regular_korean_war:3-1`
- `regular_joseon_diplomacy:1-1`, `2-1`, `3-1`
- `regular_independence_army:3-1`
- `regular_goryeo_culture:1-1`

각 단계에서 다음만 확인한다.

- 자료 재확인·비교 활동으로 자연스럽게 복귀하는가
- 초등학생이 문장을 이해할 수 있는가
- 가상 실패 결과와 실제 역사 사실이 구분되는가
- 폭력·공포·죄책감·집단 비하·정답 감정 강요가 없는가
- 기존 출처 범위를 벗어난 새 주장이나 수치가 없는가

보고서는 각 단계에 대해 `승인 가능 / 사용자 확인 필요 / 수정 제안`만 표시한다. 문구는 수정하지 않는다.

## 2. `regular_sejong` 중복 키 확인

파일: `data/mud/regular_sejong.json`

다음 단계의 simulator 중복 키를 확인한다.

- `2`: 칠정산
- `3`: 앙부일구

각 단계에서 다음을 표로 제시한다.

- 현재 파서가 사용하는 마지막 `instruction`·`feedback`
- 유지 권장하는 첫 번째 자료 중심 `instruction`·`feedback`
- 삭제 대상 중복 키
- 삭제 시 hotspot·infoText·completion에 영향이 없는지

`1`, `2-1`, `3-1`, `4`에는 같은 문제가 없는지도 확인한다.

사용자 승인 전에는 중복 키를 삭제하지 않는다.

## 사용자에게 보여줄 최종 승인 문구

보고서 마지막에 다음 두 결정을 분리해 제시한다.

1. `IF 6개 최종 승인`: 추가 수정 없음 여부
2. `regular_sejong` 2·3단계 중복 키: 자료 중심 앞 문구 유지 및 뒤 중복 문구 삭제 승인 여부

## 결과 보고

- 확인 파일·명령·브라우저 결과를 간단히 기록한다.
- JSON·JS·문서 변경 없음
- 커밋·push 없음
- 수정이 필요하면 사용자 승인 후 별도 작업으로 진행
