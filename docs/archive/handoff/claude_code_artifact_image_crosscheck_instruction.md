# Claude Code 작업 지시서 — 유물·보상 이미지 정합성 교차 검증

## 목적

사용자 검토에서 유물·보상 설명과 표시 이미지(현재 `icon` 이모지)가 서로 완전히 다른 사례가 많다는 의견이 있었다. 유물명·설명·아이콘·MUD 보상 연결이 같은 대상을 가리키는지 확인한다.

이번 작업은 **검증과 보고가 우선**이며, 승인 없이 JSON·JavaScript를 수정하지 않는다.

## 필수 검토 대상

다음 6개 유물을 먼저 전수 대조한다.

- `art_1`
- `art_3`
- `art_4`
- `art_15`
- `art_16`
- `art_18`

가능하면 `data/artifacts.json`의 전체 36종도 훑어, 동일한 유형의 명백한 이미지 불일치를 추가로 보고한다.

## 대조 범위

- `data/artifacts.json`의 `id`, `name`, `era`, `icon`, `desc`, `category`, `hint`
- 각 유물의 MUD 보상 연결: `data/mud/*.json`의 `rewards[].artifactId`와 `rewards[].name`
- 실제 도감 표시 코드: `js/encyclopedia.js`
- 보상 표시 코드: `js/mudEngine.js`, 필요 시 `js/storyEngine.js`
- 브라우저 도감 카드와 MUD 완료 보상 화면

## 확인 기준

1. `icon`이 유물의 실제 종류·형태·기능을 최소한으로라도 나타내는가.
2. 아이콘이 유물과 전혀 다른 물건·시대·상징을 가리키지 않는가.
3. 유물명·설명·힌트가 아이콘과 서로 모순되지 않는가.
4. MUD 보상 `artifactId`와 보상명이 도감의 같은 유물로 연결되는가.
5. 같은 이모지가 역사적 의미를 왜곡하거나 국가·정치·전쟁 이미지를 불필요하게 연상시키지 않는가.
6. 초등학생이 아이콘만 보고 잘못된 유물로 이해할 가능성이 큰가.
7. 아이콘 문제가 단순한 시각 표현 문제인지, 유물명·설명·보상 데이터 자체의 문제인지 구분한다.

## 브라우저 확인

- 도감에서 필수 6종 카드의 아이콘·유물명·설명을 확인한다.
- 해당 유물을 보상하는 대표 MUD를 하나 이상 열어 완료 보상명이 도감과 일치하는지 확인한다.
- 콘솔 오류와 이미지/아이콘 로딩 오류가 있는지 확인한다.
- 실제 표시가 emoji인지 별도 이미지 파일인지 코드로 확인한다.

## 변경 제한

- `data/artifacts.json`, `data/mud/*.json`, `js/encyclopedia.js`, `js/mudEngine.js`, `js/storyEngine.js`를 수정하지 않는다.
- 아이콘 교체가 필요해 보여도 임의로 바꾸지 않는다.
- 유물명·설명·시대·등급·보상 ID를 아이콘에 맞추기 위해 변경하지 않는다.
- 역사적 사실 확인이 필요한 경우 사실성 문제와 이미지 정합성 문제를 분리해 보고한다.
