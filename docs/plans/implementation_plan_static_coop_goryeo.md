## 3. 기준 모델과 형식 대응

`cooperative-mud/han-river/`를 기준으로 삼는다. 진행 순서는 다음과 같다.

```text
내 역할 자료 → 최초 판단(혼자) → 자료 나누기(말로) → 새 자료 공개·생각 유지/변경
→ [10분형] 새 상황 토론 → 모둠 설명 문장 → 학자 관점 비교
```

### 3-1. 교과서 연결 (D-039)

기준은 2단원 8차시 「조선 후기의 경제적 변화」(교과서 95~96쪽, 94쪽은 주제 도입)다. 원문은 `primary_data/society_5-2-2.pdf`(로컬 전용, **GitHub 업로드 금지**)에서 확인했다(2026-10-15). 저장소에는 아래처럼 짧은 대조만 남긴다.

| 교과서 갈래 | 학생 역할 | 교과서 본문 | 역할에 줄 교과서 사료 |
|---|---|---|---|
| 모내기법 확산 (95쪽) | 🌾 모내기 농민 | 쌀 생산량 증가, 벼 추수 뒤 보리 심기, 적은 일손으로 넓은 땅 → 잘사는 농민 | 이익 『성호사설』(노동력 5분의 4 절감), 『일성록』(10두락 → 20~40두락), 「경직도」 |
| 상품 작물 (95쪽) | 🌶️ 상품 작물 농민 | 고구마·감자·고추·담배는 외국에서 들어옴. 고구마·감자는 척박한 땅에서도 자라 굶주림을 덞. 고추·인삼·담배는 팔아 큰 이익 | 정약용 『경세유표』(담배·모시·생강·고구마밭 이익이 가장 좋은 논의 10배) |
| 장시·보부상 (96쪽) | 🎒 보부상 | 사고파는 일이 늘어 전국에 장시, 여러 장시를 도는 보부상 증가 | 권용정 「등짐장수」 |
| 상평통보 (96쪽) | 🪙 화폐 담당 관리 | 상업 발달 → 상평통보를 만들어 전국에서 사용. 그 전에는 쌀·옷감으로 사고팖 | 『숙종실록』(신하들이 화폐의 편리함을 말함) |
| (자료 읽기) | 📜 기록관 | — | 사료마다 누가·왜 썼는지, 이 사료로 알 수 없는 것 |

| 인원 | 역할 |
|---|---|
| 3인 | 모내기 농민·상품 작물 농민·보부상(상평통보 포함). 교과서 지도안의 직소 구조와 같다 |
| 4인 | 모내기 농민·상품 작물 농민·보부상·화폐 담당 관리. 장시와 상평통보를 나눠 교과서 96쪽의 두 문장을 따로 맡긴다 |
| 5인 | 4인 + 기록관 |

- 교과서 96쪽 발문 "상평통보가 만들어지게 된 까닭"과 "백성은 어떤 점이 편했을지"를 모둠 대화와 최초 판단 질문에 그대로 쓴다.
- 교과서 96쪽 「꼭 기억해요」(모내기법 확산 → 쌀 생산량 증가, 상평통보 전국 사용)를 학자 관점 비교 자리에 둔다.
- 97쪽(다음 차시: 잘살게 된 사람의 양반 신분 매매)은 10분형 새 상황의 예고로만 쓰고, 이번 활동의 사실 서술에는 넣지 않는다.

- 모둠 설명 문장은 교과서 평가 기준에 맞춰 **농업 변화 → 상업 변화 → 사람들 생활**로 짠다.
- 원본 실시간 시나리오의 전황·호적 누락 30%·고공 세곡 하역은 학생 화면에서 빼고 `TEACHING.md` 발문 자료로 옮긴다.
- 원본의 출처 8건은 교과서 범위 안의 서술(모내기법·장시·상평통보·수공업)에 맞는 것만 남기고, 상품 작물 출처를 새로 확인한다.

## 5. 새로 써야 할 콘텐츠 (사용자 검토 대상)

원본에 없는 부분이다. 모두 `docs/audits/joseon_late_source_review.md`에서 이미 확인한 출처 범위 안에서 쓴다. 범위 밖 사실이 필요하면 출처를 먼저 확인한다.

교과서 원문을 확인한 뒤 정리한 후보다.

1. **역할 자료 전면 재작성** — 교과서 본문과 사료를 역할별로 나눠 쓴다. 상품 작물 농민과 화폐 담당 관리는 새 역할이다. 역할별 말하기 첫 문장(shareText)과 최초 판단 선택지도 함께 쓴다.
2. **새 자료 공개(reveal)** — 자료를 나눈 뒤 모둠 전체에 보여 주는 자료 1개. 세 갈래가 서로 이어진다는 것을 깨닫게 하는 자료가 목표다. 후보:
   - A. 교과서 96쪽 말풍선 "상평통보가 널리 사용되기 전에는 주로 쌀과 옷감으로 물건을 사고팔았어요" → "남는 쌀과 상품 작물이 늘어나는데 쌀로만 사고팔면?"
   - B. 『경세유표』 "고구마밭 이익이 가장 좋은 논의 10배"(3인 모둠에서 상품 작물 역할이 없을 때를 대비해 공개 자료로 돌림)
3. **10분형 새 상황(second)** — 세 갈래를 하나로 잇는 상황. 예: "모내기로 일손이 남은 농민이 담배를 길러 장시에서 상평통보를 받고 팔았다. 이 농민의 한 해에서 농업 변화와 상업 변화를 모두 찾아보자." 마지막에 97쪽으로 이어지는 질문("돈을 많이 번 이 농민은 다음에 무엇을 하고 싶었을까?")을 둔다.
4. **학자 관점 비교(compare)** — 교과서 정리 문장(모내기법 → 쌀 생산 증가, 사고파는 일 증가 → 장시 발달)을 학자 관점 자리에 두고, 학생 판단과 비교한다.
5. 타이머 질문형 힌트(단계별 slow·fast), 10분형 문장 제목·설명.

## 6. 콘텐츠 원칙

- **교과서 우선**: 학생 화면의 사실 서술은 교과서 94~96쪽 범위 안에서, 교과서 용어(모내기법, 상품 작물, 장시, 상평통보, 보부상)를 그대로 쓴다.
- 한 고을·한 장시의 사례를 조선 후기 전체로 넓히지 않는다(기존 `limitations` 유지).
- 추론 문장을 사실처럼 쓰지 않는다(감사 C1-04). 역할 본문의 "~것입니다"·"~것 같아" 같은 추정 표지를 유지한다.
- 출처 URL과 확인일은 원본 그대로 옮긴다.
- 5학년 2학기 교과서 수준의 어휘를 쓴다. 광작·전황·고공처럼 어려운 말은 괄호 풀이를 유지한다.
