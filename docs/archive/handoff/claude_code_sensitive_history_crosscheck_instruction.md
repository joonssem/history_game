# Claude Code 작업 지시서 — 민감한 역사 내용 교차 검증

## 목적

Codex의 1차 검토에서 `regular_japanese_rule_2` 1~3단계의 민감한 역사 내용은 대체로 적절하다는 판단을 받았다. 다음 단계로 학습 문구·상호작용·장면이 서로 같은 교육적 의도를 가리키는지 교차 검증한다.

이번 작업은 **검증과 보고가 우선**이며, 승인 없이 학습 내용을 수정하지 않는다.

## 대상

- `data/mud/regular_japanese_rule_2.json`: 1-1, 2-1, 3-1
- 각 단계의 `instruction`, `infoText`, `feedback`, `narrative`, `completion`
- 각 단계의 `simulator.scene`, `simulator.hotspots`, `simulator.interaction`
- 관련 `glossary`·출처·Phase 38 장면 렌더러

## 교차 검증 항목

1. `narrative`가 제시하는 역사 상황과 `instruction`/`infoText`의 활동 목표가 일치하는가.
2. `feedback`가 사실 설명과 자료 관찰을 돕고, 피해자의 감정이나 기억을 정답으로 강요하지 않는가.
3. `completion`이 피해 상황의 재현·감정 소비가 아니라 자료 확인과 역사적 이해를 기준으로 하는가.
4. 장면의 도상과 hotspot이 학습 문구와 일치하며, 군인·무기·폭력·피해 장면을 불필요하게 연상시키지 않는가.
5. 강제 동원·전시 성폭력·언어 억압 관련 표현이 선정적·비하적·과장되지 않았는가.
6. 초등학교 5학년 수준에서 문장의 의미와 활동 방법을 이해할 수 있는가.
7. 단계 간 흐름이 정책·통제 → 강제 동원과 피해 기억 → 언어 운동이라는 학습 순서를 유지하는가.
8. 실제 코드가 읽는 값과 JSON에 중복·불일치·오탈자가 없는가.

## 변경 제한

- `instruction`, `infoText`, `feedback`, `narrative`, `completion`, `simulator` 필드는 수정하지 않는다.
- 장면을 바꿔야 할 가능성이 있으면 먼저 파일명·단계 ID·필드·이유·예상 교육 효과를 보고한다.
- 새로운 피해 사례·수치·장소·증언을 임의로 추가하지 않는다.
- 기존 출처와 프로젝트 문서에 근거가 없는 표현은 사실처럼 보강하지 않는다.
