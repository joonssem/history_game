## 사용법 (다른 창에게)

각 주제 표의 "말하지 않는 것" 칸은 **문안에 쓰면 안 되는 방향**이다. "지역·신분·시기 차이" 칸은 그대로 문장에 녹이면 좋은 헤지 표현이다. 예를 들어 "장시가 전국에 퍼졌다"는 18세기 말 기준으로는 맞지만, 그 이전 시기·특정 학생 캐릭터의 설정 연도에는 안 맞을 수 있다 — `firstJudgment`나 역할 카드에 연도를 넣을 때 이 표의 "시기차" 칸을 확인한다.

## 1. 장시(場市)

| 항목 | 내용 |
|---|---|
| **원문이 말하는 것** | 15세기 말 전라도 무안·나주 등지의 흉년 대응(한 달에 두 번 장문을 여는 것)에서 시작해, 개시 주기가 15일·10일 간격에서 점차 **5일장**으로 짧아졌다. **18세기 말 전국 장시 수가 1,000곳**에 달했고, 일부 지역은 한 달 내내 근처 어딘가에 장이 섰다. 장시의 "주인"은 **농민**이었고, 농민·수공업자가 잉여 생산물을 팔고 필요한 물건을 사는 활동이 일반화됐다. |
| **원문이 말하지 않는 것** | "모든 마을에 장시가 있었다"거나 "장시가 등장하자마자 전국에 퍼졌다"는 서술은 근거가 없다 — 확산은 15세기 말부터 18세기 말까지 **약 300년에 걸친 점진적 과정**이었다. 장시가 **매일** 열렸다는 서술도 틀렸다(5일장 체계). |
| **지역·신분·시기 차이** | 시작 지역은 전라도(무안·나주)이며 이후 전국으로 확산되기까지 시간이 걸렸다. "18세기 말 1,000곳"은 특정 시점의 수치이지, 조선 후기 내내 그랬던 게 아니다 — 예를 들어 17세기 초 장면에 "전국에 장시 1,000곳"이라고 쓰면 시기 오류다. |

## 2. 화폐(상평통보)

| 항목 | 내용 |
|---|---|
| **원문이 말하는 것** | **1678년(숙종 4)**부터 주조·법정화폐로 유통 시작(같은 해 「행전절목」 제정, 4월부터 정식 법정 통화). 배경은 농업 생산력 증가 → 상업 발달 → 교환 수단 수요 증가. 서울에서는 국가 허가 없이 파는 **난전**이 시전 상인을 위협할 만큼 성장했고, **지방 시장에서는 5일장 체계가 점차 확대**됐다. 18세기 후반~19세기 중엽에 더 광범위하게 퍼졌다. **영조대 초반에는 동전이 부족해지는 '전황(錢荒)' 현상**도 나타났다(축장 때문, 폐전론으로 이어짐). |
| **원문이 말하지 않는 것** | "상평통보가 나오자마자 전국에서 즉시 쓰였다"는 서술은 근거가 없다 — 초기엔 서울·각 아문 중심으로 퍼졌고, 광범위한 유통은 18세기 후반~19세기 중엽에야 이루어졌다. "화폐경제가 발달해 모든 사람이 편해졌다"도 과장이다 — 전황처럼 화폐가 **부족해 문제가 된 시기**도 있었다. |
| **지역·신분·시기 차이** | 서울(시전·난전 갈등)과 지방(5일장 확산)의 양상이 다르게 서술된다. 초기(1678년 직후)와 후기(18세기 후반 이후)의 유통 범위가 다르다 — "1678년에 전국 화폐경제가 완성됐다"는 시기 오류다. |

## 3. 농업 생산(모내기법/이앙법)

| 항목 | 내용 |
|---|---|
| **원문이 말하는 것** | 이앙법은 조선 초기엔 가뭄 피해 우려로 **법으로 금지**됐다가(1414년 실록 기록), **17세기 이후 빠르게 보급**되며 17세기 중엽부터는 국가도 막을 수 없게 됐다. **삼남지방(충청·전라·경상)을 중심**으로 확산돼 17세기 말에는 삼남지방에서 "대세"를 이뤘다 — "호남 백성은 오로지 이앙을 하고 직파는 1/100에 불과하다"는 기록도 있다. 확산의 조건은 **수리시설 증가**였고, 물 확보가 되는 곳과 안 되는 곳을 구별해 이앙 여부를 정하는 정책이 있었다. **이앙법 보급이 광작(넓은 농지 경작)을 자동으로 일반화시킨 것은 아니다**(별도 조건 필요). |
| **원문이 말하지 않는 것** | "모내기법이 전국에서 동시에 시작됐다"는 틀렸다 — 삼남지방이 먼저였고 확산엔 시차가 있다. "모내기법 덕분에 모든 농민이 부유해졌다"도 과장이다 — 광작으로 이어진 것은 조건부였고, 반대로 땅을 잃는 농민도 있었다(계층 분화, 이 표에서 상세히 다루지 않음 — 필요하면 추가 대조). |
| **지역·신분·시기 차이** | 지역차가 원문에 명시적으로 있다(삼남지방 우선, 수리시설 있는 곳 우선). 시기차도 뚜렷하다 — 15세기(금지) → 17세기(빠른 보급) → 17세기 말(삼남 대세). 신분차(지주 vs 소작농의 이해관계 차이)는 이 두 원문에서 직접 다루지 않아 **확인 불가**로 남긴다. |
| **출처** | 우리역사넷 「이앙법의 보급」(`contents.history.go.kr/mobile/nh/view.do?levelId=nh_033_0020_0020_0010_0010`), 「광작과 지주제」(`nh_033_0020_0030`), 「16세기 이앙법의 보급 및 확산」(`km_027_0050_0030_0030`), WebFetch 직접 열람, 2026-09-16. |

## 4. 수공업·광업

| 항목 | 내용 |
|---|---|
| **원문이 말하는 것** | 조선 초기엔 관청 수공업이 중심이었으나 **조선 후기엔 점차 쇠퇴하고 민영 수공업이 발달**했다. 광업은 **1651년(효종 2) 설점수세제** 시행으로 정부가 연(鉛)·은(銀) 생산지에 '설점'하고 세금을 거두는 방식이 도입돼 민간 채굴이 늘었다. **19세기엔 설점수세제가 물주제(物主制)로 바뀌며 광산 개발이 더 활발해졌다.** |
| **원문이 말하지 않는 것** | "조선 후기에 모든 광업이 민영화됐다"는 과장이다 — 확인된 원문은 **연·은 생산지**를 중심으로 서술하며, 금(金) 등 다른 광물까지 일반화한 근거는 없다("금에 대한 명시적 언급은 없음"). "수공업이 하루아침에 민영으로 바뀌었다"도 근거 없음 — "점차" 쇠퇴·발달이라는 완만한 과정으로 서술된다. |
| **지역·신분·시기 차이** | 시기차가 뚜렷하다: 1651년(설점수세제 도입) → 19세기(물주제로 전환). 광물별 차이도 있다(연·은이 우선 대상). 지역차는 이번 대조에서 **확인 불가**(원문이 특정 광산 지명을 일반화해 제시하지 않음) — 필요하면 개별 광산(예: 함경도 광산 등) 조사 후속 필요. |
| **출처** | 우리역사넷 「설점수세제」(`contents.history.go.kr/front/tg/view.do?treeId=0209&levelId=tg_003_1920`), WebFetch 직접 열람, 2026-09-16. |

## 5. 생활·서민 문화

| 항목 | 내용 |
|---|---|
| **원문이 말하는 것** | 조선 후기엔 "양반을 중심으로 유교 테두리 내에서 이루어지던 문예 활동에 **중인층과 서민층이 참여**하여 큰 변화가 나타났다." 구체적으로 **역관·서리 등 중인층, 상공업 계층, 부농층**의 문예 활동이 활발해졌고, **상민·광대**의 활동(판소리 등)도 활기를 띠었다. 한글 소설은 평범한 인물이 주인공인 현실적 이야기가 많았다. |
| **원문이 말하지 않는 것** | "서민 문화는 서민만 즐겼다"는 틀렸다 — 원문은 **중인·상공업 계층·부농층까지 포함**한다고 명시한다. "조선 후기에 신분제가 완전히 사라졌다"도 틀렸다(§ 아래 신분제 항목 참조) — 문화 향유층이 넓어진 것과 신분제 자체의 법적 폐지(1894년 갑오개혁)는 다른 이야기다. |
| **지역·신분·시기 차이** | 신분차가 핵심이다 — 양반 전유물이던 문예 활동에 중인·서민이 "참여"한 것이지 양반이 빠진 게 아니다. 지역차(도시 vs 농촌)는 이 원문에서 **직접 다루지 않아 확인 불가**로 남긴다. |
| **출처** | 우리역사넷 「서민 문화의 발달」(`contents.history.go.kr/mobile/ta/view.do?levelId=ta_h71_0070_0040_0040_0010`), WebFetch 직접 열람, 2026-09-16. |

### 부록 — 신분제 동요(다섯 주제와 자주 엮이는 배경 지식)

문항·역할 카드가 "양반이 늘었다/신분제가 흔들렸다"를 언급할 가능성이 높아 별도로 확인했다.

| 항목 | 내용 |
|---|---|
| **원문이 말하는 것** | 호적대장(대구부·울산부·단성현·언양현·진해현) 연구에 따르면 양반 호(戶) 비율이 **17세기 후반 9~19% → 18세기 전반 12~26% → 18세기 후반 24~57% → 19세기 39~80%**로 늘었다(지역별 편차 큼). 공명첩 구매·족보 매입/위조로 신분 상승을 꾀하는 사람들이 있었고, "신분직역이 상향조정되면서 상향 평등화의 방향으로 신분직역제가 **해체되어 가던**" 것으로 서술된다. |
| **원문이 말하지 않는 것** | "신분제가 사라졌다/폐지됐다"는 이 원문의 표현이 아니다 — "해체되어 **가던**"(진행형)이라고만 한다. 법적 신분제·노비제 폐지는 1894년 갑오개혁(이 검토표 범위 밖, 조선 후기 시점엔 아직 아님). |
| **지역·신분·시기 차이** | 지역마다 양반 비율 편차가 크다(예: 대구·단성 등 지역별로 수치가 다름 — 위 범위는 여러 지역 수치를 묶은 것). "19세기 39~80%"처럼 시기가 늦을수록 비율도 넓은 편차로 커진다 — 특정 연도·지역을 지목하지 않고 "조선 후기 내내 70%였다"처럼 단일 수치로 쓰면 과장이다. |
| **출처** | 우리역사넷 「양반인구의 증가」(`contents.history.go.kr/mobile/nh/view.do?levelId=nh_034_0020_0010_0010`), WebFetch 직접 열람, 2026-09-16. |

## 과잉 단정 점검표

지시서 §0-2-4가 지목한 5개 금지어(**모든 사람·전국·즉시·누구나·완전히**)가 이 다섯 주제에서 왜 위험한지 한 줄씩 정리했다. 문안을 쓸 때 이 표를 체크리스트로 쓴다.

| 주제 | "모든 사람/누구나"가 위험한 이유 | "전국"이 위험한 이유 | "즉시/완전히"가 위험한 이유 |
|---|---|---|---|
| 장시 | 장시의 "주인"은 농민이라 서술되지만 참여 형태·빈도는 균일하지 않았다(5일장 주기 자체가 "항상"이 아님을 보여줌) | 18세기 **말**에야 1,000곳에 달했다 — 그 이전 시기 장면에 "전국"을 쓰면 시기 오류 | 15세기 말~18세기 말까지 약 300년에 걸쳐 점진적으로 퍼진 과정이라 "즉시"·"곧바로 전국화" 서술은 틀림 |
| 화폐(상평통보) | 서울(시전·난전)과 지방(5일장)의 유통 양상이 달라 "누구나 동일하게 썼다"는 근거 없음 | 초기엔 서울·각 아문 중심, 광범위한 유통은 18세기 후반~19세기 중엽 | 1678년 법정화폐 지정 직후 "완전히" 자리 잡았다고 하면 틀림 — 영조대 '전황'처럼 화폐가 부족해진 시기도 있었음 |
| 농업 생산(이앙법) | 지주와 소작농의 이해관계 차이는 이번 대조에서 확인 불가 — "모든 농민이 이득을 봤다"는 단정 금지 | 삼남지방이 먼저, 확산엔 지역차가 뚜렷함(수리시설 여부가 조건) | 15세기엔 법으로 금지됐다가 17세기에 "빠르게" 퍼진 것이지 "즉시" 퍼진 게 아님(수리시설이 갖춰져야 가능) |
| 수공업·광업 | 이 다섯 주제 중 가장 근거가 빈약한 영역 — 광물별(연·은 중심) 차이가 있어 "모든 광업"이라고 뭉뚱그리면 안 됨 | 설점수세제의 지역별 적용 범위는 확인 불가 — "전국 광산"이라고 단정하지 않는다 | 관청 수공업→민영은 "점차" 쇠퇴·발달한 과정, "완전히 민영화됐다"는 과장 |
| 생활·서민 문화 | "서민 문화"라는 이름과 달리 향유층은 중인·상공업 계층·부농층까지 포함 — "서민만"이라고 쓰면 오히려 틀림 | 도시·농촌 지역차는 확인 불가 — "전국에서 똑같이 유행했다"는 단정 금지 | "신분제가 완전히 사라졌다"는 원문 표현("해체되어 가던")과 다름 — 조선 후기 시점엔 아직 진행형 |
