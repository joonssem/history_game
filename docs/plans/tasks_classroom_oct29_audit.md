- `apps/cooperative-live`에 구현·등록된 활동은 고조선 8조법과 1단원 13차시 고려 건국이다. 15~18차시 두 활동은 계획만 있고 구현되지 않았다.
- 10/29 수업의 정적 대체 운영 자료는 [고려 15~18차시 카드·활동지](../handoff/claude_goryeo_oct29_source_table.md)다.
- 그러므로 이 감사는 (1) 기존 배포 앱의 기능 회귀 및 수업 차단 요인, (2) 미구현 활동의 콘텐츠·운영 준비도 판정을 분리한다. 계획을 실제 수업용 기능으로 오인시키지 않는다.
- 기본 작업은 코드·콘텐츠 읽기 전용 감사다. 발견된 문제는 이 체크리스트 결과 또는 BACKLOG에 재현 정보와 함께 남긴다. 별도 승인 없이 같은 세션에서 수정하지 않는다.

## A. 기존 구현 활동 기능 검사

기준 범위: 교사 세션 생성·편성·시작·진행, 학생 QR/코드 입장과 복구, 역할 정보 비공개, 최초 판단·공유·공동 초안·확인, 도움 요청, pause/resume, 종료 및 삭제.

- [ ] 실제 기준 브랜치·커밋과 Preview 소스를 기록한다. 작업 중 브랜치가 바뀌면 중단한다.
- [ ] 구현 시나리오 ID·버전과 교사 UI에서 선택 가능한 목록이 일치한다.
- [ ] Auth0 설정 미완료 상태에서도 어떤 화면·경로가 허용 또는 차단되는지 구분한다. OAuth 성공으로 추정하지 않는다.
- [ ] QR 및 수동 코드 입장, 중복 요청, 새로고침·재접속·자리 복구의 코드 경로와 자동 회귀를 대조한다.
- [ ] 3·4·5인 편성, 부족 인원 복구, 역할 중복·공통 자료 규칙을 확인한다.
- [ ] 학생 응답 DTO에 다른 역할의 비공개 본문이나 개인 판단 원문이 포함되지 않는지 확인한다.
- [ ] 최초 판단 전 자료 노출, 공유 완료 관문, 근거 출처 소유권, draft revision 재확인 규칙을 확인한다.
- [ ] 한 모둠 진행·교사 도움 요청/해제·pause/resume가 다른 모둠에 영향을 주지 않는지 확인한다.
- [ ] 학생 재접속 뒤 본인 역할·모둠·진도 복구, 이전 토큰 무효화 및 종료 후 세션 하위 데이터 삭제 경로를 확인한다.
- [ ] 모바일·태블릿 교사 QR 표시와 학생 핵심 버튼의 터치 크기·가로 넘침을 검사할 수 있는 자동/브라우저 증거를 분류한다.
- [ ] 2026-10-01 기록의 자동 테스트 결과와 현재 checkout 코드를 혼동하지 않는다. 실제 4~8대 기기 리허설은 별도 증거가 없으면 미완료로 둔다.

## B. 15~16차시 콘텐츠 감사 — 고려와 주변 나라들의 관계

- [ ] 거란 관계(서희 담판·강동 6주·귀주대첩)와 몽골 침입·삼별초를 서로 다른 시기·맥락으로 구분한다.
- [ ] 외교·방어·전투를 단일 영웅의 선택이나 “말만으로 영토 획득” 서사로 축소하지 않는다.
- [ ] 국가의 대응과 전쟁이 백성의 생업·피난·세금에 미친 영향을 함께 다룬다.
- [ ] 고려·거란·송·여진 및 몽골과의 관계를 고정된 적대 집단이나 현대 민족과 단순 대응하지 않는다.
- [ ] 역할별 근거, 3·4·5인 편성의 공통 자료, 한계 자료가 계획된 공동 산출물과 맞물리는지 확인한다.
- [ ] 주장별 공식 출처·열람일·허용 범위가 역할 문장에 연결되어 있는지 확인한다. 출처 표기가 없는 사실 문장은 별도 보고한다.
- [ ] 5학년 학생이 읽고 말할 수 있는 문장 길이·낯선 용어 풀이·역할별 고유 판단권을 점검한다.

## C. 17~18차시 콘텐츠 감사 — 고려 문화와 사람들의 생활

- [ ] 청자 제작·사용, 팔만대장경의 제작 맥락, 직지·금속활자 기술을 사실 범위 안에서 구분한다.
- [ ] 가족·상속·신분·생업 자료를 모든 시대·계층·지역의 보편 관습으로 과장하지 않는다.
- [ ] 문화유산의 기술적 우수성만 평가하게 하지 않고 만든 사람·사용한 사람·노동·생활 맥락을 연결한다.
- [ ] 왕실·사찰·상층 자료만으로 모든 고려인의 생활을 대표할 수 없다는 자료 한계를 포함한다.
- [ ] 청자·가족/상속·불교문화·인쇄 역할이 고유한 근거를 제공하고, 공동 설명이 서로 다른 두 역할 근거 없이는 성립하지 않는지 확인한다.
- [ ] 공식 소장·관리 기관 또는 교과서 범위의 출처가 명시되어 있는지 확인한다. 출처 미대조와 역사 오류를 구분해 기록한다.
- [ ] 벽란도 자료는 계획대로 보조 교류 자료로 쓰이는지, 핵심 학습 초점을 과도하게 넓히지 않는지 확인한다.
- [ ] 선택 red-team(2026-10-02): 관계 카드 D·E는 삼별초·복속을 정복/독립 한쪽으로 단정하지 않고, 관계 카드 C의 피해는 몽골 시기 R9에 한정된다. 문화 카드 A·E의 청자 사용층은 왕실·개경 관료·사찰의 근거와 평범한 백성 사용의 자료 부재를 구분한다. 단, 문화 카드 E의 “농민·장인 같은 평범한 사람들의 이야기가 적다”는 문장은 카드 묶음 전반의 한계로 확대될 수 있으므로 교실 적용 전 이 표현을 읽는 방식 확인이 필요하다. 카드 E §8도 이 추론은 출처 표 A-2 한계에 따른 것이며 교과서 대조 전 확정하지 말라고 명시한다. 카드 문안 수정 없이 관찰 항목으로 남긴다.
