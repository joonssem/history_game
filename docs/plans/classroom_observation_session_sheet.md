# 수업 관찰 기록지 — 한 차시 전체용

> 2026-09-15 기획 세션(Opus) 제안. 사용자가 다음 개발 라운드보다 수업 관찰을 먼저 하기로 결정했다(`DECISIONS.md` D-033).
> 기존 [`classroom_observation_inquiry_pilot.md`](classroom_observation_inquiry_pilot.md)는 **학생 1명이 파일럿 MUD 1편을 하는 장면**을 본다. 이 문서는 그 위에 **한 차시 수업 전체**(도입→MUD→확장 활동→정리)와, 라운드 4·5에서 고친 곳이 교실에서 통하는지를 더한다.
> **두 기록지는 같이 쓴다.** 교사 1명이 다 채우기 어려우면 A(학급 전체)만 쓰고, B(학생 3명 추적)는 가능할 때 쓴다.

## 0. 관찰 전에 정할 것

| 항목 | 권장 | 이유 |
|---|---|---|
| 차시 | 1단원 파일럿 편이 들어간 차시 1회 + 확장 활동을 쓰는 차시 1회 | 파일럿 inquiry-task와 사실 대조를 마친 확장 활동을 모두 볼 수 있음 |
| 추적 학생 | 3명(상·중·하) | 기존 파일럿 기록지와 같은 기준 |
| 기기 | 실제 수업 기기 그대로 | 실험실 조건이 아니라 교실 조건을 본다 |
| 기록 | 종이 기록지 + 끝나고 5분 안에 자유 메모 | 기억이 흐려지기 전에 남긴다 |
| 사전 확인 | 배포본이 `ae5bfbc` 이후인지(첨성대·측우기·금동대향로 문구로 확인) | 고친 문구를 보고 있는지 확인 |

**개인정보:** 이름 전체, 얼굴 사진, 화면 녹화 속 얼굴은 남기지 않는다. 학생은 교사 내부 약칭으로만 적는다.

## A. 학급 전체 기록지 (차시당 1장)

```

■ 시간 흐름 (실제 시각을 적는다)
  도입 ____ ~ ____   MUD ____ ~ ____   확장 활동 ____ ~ ____   정리 ____ ~ ____
  계획 대비: [ ]맞음  [ ]MUD가 길어짐  [ ]확장 활동을 못 함  [ ]기타 ______

  조용히 몰입 |      |      |      |

  (칸에 대략 몇 명인지 적는다)

■ 교사 한 줄 판단
  다음 차시에 그대로 쓸 수 있나: [ ]그대로 [ ]설명을 더해서 [ ]바꿔야 함
  가장 먼저 고칠 한 가지: ________________________________
```

## C. 이번 관찰에서 특히 볼 곳 (라운드 3~5에서 고친 곳)

고친 문구가 **학생에게 실제로 다르게 읽히는지** 본다. 자동 검사는 이것을 판정하지 못한다.

| 화면 | 고친 내용 | 볼 것 |
|---|---|---|
| 신석기 1·2관문 | "가장 먼저", "완성" 같은 단정을 낮춤 | 학생이 여전히 "하나뿐인 정답"을 찾으려 하는지 |
| 삼국 3관문 | 순서 노출 제거, 연도 비교 안내 | 연도를 실제로 비교하는지 (B-10) |
| 근대 3관문 | 오답 피드백에서 정답 장소 이름 제거 | 피드백 뒤 기록을 다시 읽는지, 남은 보기만 누르는지 |
| 원인·결과 고려 세트 | "안정을 되찾은 고려는"을 "그 무렵 고려는"으로 낮춤 | "때문에"와 "그 무렵"을 학생이 구분하는지 (B-11) |
| 골든벨 quiz_7 | 측우기 발명 주도자를 왕세자(문종)로 정정 | "장영실 아니에요?" 같은 반응 — 해설이 설득되는지 |
| 타임머신 금동대향로 | 성왕 → 위덕왕 | 이름이 바뀐 것에 학생이 혼란스러워하는지 |
| 유물 도감 심화 보상 | "상징적 표현"임을 밝힘 | 실물로 오해하는지 |

## D. 3단원을 관찰할 때 (D-032로 수정 금지가 풀림, 사실 대조는 아직 안 함)

- 3단원 편은 **사실 대조 전**이다. 관찰 차시로는 1·2단원을 권한다.
- 3단원을 쓸 경우, 학생이 말하거나 되물은 **사실 문장을 그대로 적어 두면** 라운드 6 사실 대조의 우선 대상이 된다.
- 민감한 주제(일제강점기, 6·25)에서 학생의 감정 반응이나 한쪽 극단 표현이 나오면 내용만 짧게 적는다. 학생 이름은 적지 않는다.

## E. 기록 뒤 처리

1. 끝나고 5분 안에 자유 메모를 쓴다.
2. 결과는 `EXPERIMENTS.md`에 "관찰 → 가설 → 다음 결정" 형식으로 옮긴다. 기록지 사진은 저장소에 올리지 않는다(개인정보).
3. **한 번의 관찰로 요구사항을 확정하지 않는다.**
   - 두 학급 이상에서 같은 현상이 보이면 BACKLOG로 올린다.
   - 한 번만 보였으면 "가설"로 둔다.
4. 기획 세션에 가져올 것:
   - A의 "가장 먼저 고칠 한 가지"
   - 손 든 질문 목록
   - 틀린 사실 발화
   - C 표에서 기대와 다르게 반응한 곳
