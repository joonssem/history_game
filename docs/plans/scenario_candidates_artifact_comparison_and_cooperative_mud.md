# 유물 비교·추론 활동 및 협동 MUD 시나리오 후보 (2026-09-03 브레인스토밍)

## 문서 성격

이 문서는 Claude Sonnet 5와의 순수 브레인스토밍 산출물이다. 코드·구현·커밋은 없으며, 모든 내용은 확정 요구사항이 아닌 **검토·검증 대상 가설**이다. 구현 전 반드시 아래를 재확인한다.

- 유물 이미지의 실제 소장품번호·해상도·다운로드 가능 여부
- 협동 MUD 시나리오 각각의 폭력성·민감도, 특히 ⚠️ 표시 항목
- 학생 반응(피로도, 실제 협동 발생 여부)은 소규모 시범 전까지 가설로 유지

관련 기존 결정: 협동 MUD 첫 파일럿 소재는 이미 [`implementation_plan_cooperative_prehistory_pilot.md`](./implementation_plan_cooperative_prehistory_pilot.md)에서 **선사시대**로 확정되어 있다. 이 문서의 시나리오 후보들은 그 결정을 대체하지 않으며, **후속 파일럿 후보 풀**로 기록한다.

## 1. 유물 비교·추론 활동 ("두 유물 이야기")

### 배치 방식
기존 MUD 클리어 직후, 유물 2개 이상 모였을 때 자동으로 이어지는 짧은(30초~1분) 보너스 스테이지. 스킵 불가하지만 선택형·서술 없음으로 부담을 최소화한다.

### 흐름
관찰(두 유물의 차이 지목) → 근거 카드 선택(무늬·재질·장소 등, 무근거 선택지도 포함) → 주장 문장 완성(빈칸 채우기형) → 결과 비교(정답이 아닌 "학계 관점"으로 학생 생각과 나란히 제시)

### 유물 페어 후보 (국립중앙박물관 공식 소장품, museum.go.kr 확인)

| 단계 | 유물 A | 유물 B | 라이선스 |
|---|---|---|---|
| 1단계 | 빗살무늬토기(신석기, 서울 암사동) | 민무늬 토기 항아리(청동기, 부여 송국리, 소장품번호 신수10470) | A: 공공누리 출처표시+변경금지 / B: 출처표시 |
| 2단계 | 청자 상감 구름·학무늬 매병(고려, 덕수2182) | 백자 달항아리(조선, 접수702) | 둘 다 출처표시 |
| 2단계 | 금동 연가7년명 여래입상(고구려, 국보119호, 539년 명문) | 금동석가여래입상·정지원명(백제, M번335-2) | B 출처표시 (A relicId 미확정, 재확인 필요) |

라이선스는 대부분 공공누리 "출처표시"만 있으면 자유 이용 가능. 빗살무늬토기 1건만 "변경금지" 조건이라, 구현 시 전부 원본 이미지를 그대로 쓰는 방향으로 통일하는 것을 제안한다.

### 결과 비교 화면 톤 원칙
- "정답/오답" 표현 금지 → "학자들은 ~라고 봐" 식으로 하나의 관점처럼 제시
- 학생 생각을 먼저 언급한 뒤 학계 관점을 병치
- 학생 답이 학계 관점과 가까운지에 따라 톤을 칭찬형/안내형으로 자동 분기하되, 둘 다 "네 생각은 ~였구나"로 시작해 일관성 유지

### 후속 아이디어 — 개인 전시 준비실
해금 유물 2개 선택 → 전시 제목·주장·근거 카드 선택 → 관람객 질문 1개 응답으로 제한한 작은 실험. 기존 `localStorage` 기반 해금 유물 구조와 잘 맞는다. (2026-09-03 INBOX 항목에 이미 상세 기록됨)

### 남은 질문
- 고구려 불상의 정확한 museum.go.kr relicId
- 삼국 무덤 비교(3단계) 이미지·자료 미조사
- 실제 이미지 파일 해상도·다운로드 가능 여부
- 스킵 불가 방식의 학생 피로도

## 2. 협동 MUD — 서버 없는 절충 메커니즘

실시간 서버(WebSocket/Supabase Realtime) 도입은 아직 결정 사항이 아니므로, 교실의 물리적 동시성을 활용하는 절충안을 우선 검토한다.

- **오프라인 직소(Jigsaw)**: 학생마다 다른 URL 파라미터로 다른 정보 조각을 받고, 실제 대화로 맞춰 진행. 구현이 가장 단순해 1차 시범으로 추천.
- **QR/코드 교환**: 학생이 만든 "결과 코드"를 다른 학생 화면에 입력해 다음 장면을 여는 방식. 직소가 검증된 뒤 얹는 다음 실험으로 미룬다.

기존 INBOX 기록에 따르면 첫 파일럿은 **자리 이동형 Room**(학생이 실제로 모둠 자리로 이동해 말로 협동, iPad는 역할 단서만 보조)으로 이미 방향이 잡혀 있다. 이 문서의 시나리오들은 그 운영 모델 위에서 소재만 교체하는 후보다.

## 3. 협동 MUD 시나리오 후보 전체 목록

### 3.1 한산도 해전 (조선, 임진왜란)
- 역할: 조타수(조류) / 화포장(사거리) / 정찰병(적 배치) / 지휘관(종합 결정)
- 승패가 아니라 "학익진이 왜 효과적이었는가"로 프레임 고정. 전투 묘사·인명 피해는 최소화.
- 폭력도: 중간(전술 중심으로 완화 필요) / 난이도: 중간

### 3.2 수원 화성 축성 (조선, 정조·정약용)
- 역할: 석수(경사로 원리) / 목수(지렛대 원리) / 거중기 기술자(도르래 원리) / 감독(종합 결정)
- 파괴가 아닌 "건설"이 목표라 폭력 요소가 원천적으로 없음. 초등 과학 "여러 가지 도구로 물체 움직이기" 단원과 융합 가능.
- 과학 개념은 수식 없이 생활 비유(시소, 빨랫줄, 언덕길)로 풀고, 용어는 선택적 "더 알아보기"에 배치.
- 폭력도: 없음 / 난이도: 중간

### 3.3 팔만대장경 판각 (고려, 1236~1251년)
- 역할: 목재 준비자 / 각수(초보) / 원고 대조자(오탈자 교정) / 대장도감 책임자
- "기록을 남기는" 활동 자체가 소재라 제약(역사를 기록·기억 중심으로)과 정확히 부합. 오류 찾기가 게임 메커닉이라 학생들의 자발적 오류 제보 습관과도 연결됨.
- 폭력도: 없음 / 난이도: 낮음~중간

### 3.4 훈민정음 창제 (조선, 세종, 1443~1446년)
- 역할: 초성 담당(자음) / 중성 담당(모음) / 종성 담당(받침) / 세종 역(종합)
- 완전히 지적 활동이라 폭력 요소 없음. 국어 교과와 직접 연결.
- 소리(음성) 개념을 시각/텍스트로 표현하는 작업이 다른 소재보다 까다로워 구현 난이도는 상대적으로 높음.
- 폭력도: 없음 / 난이도: 중간~높음

### 3.5 벽란도 국제무역 (고려) — "고려의 대외 교역"과 동일 소재로 병합
- 역할: 고려 상인(팔 물건·가격) / 아라비아 상인(수은·향료, 언어 장벽) / 통역관(부분적 정보 전달) / 항구 관리인(승인 결정)
- 말이 안 통하는 상황을 정보 비대칭으로 자연스럽게 구현할 수 있는 독특한 지점. "협상 성사"가 승패처럼 느껴지지 않게 톤 설계 필요.
- 폭력도: 없음 / 난이도: 중간

### 3.6 삼국시대 묶음

#### 3.6.1 고구려·백제·신라·가야 시조 설화
- 직소형 비교. 역할별로 다른 나라 설화 카드(동명성왕/온조/박혁거세/김수로)를 받고 "알에서 태어남" 같은 공통 모티프를 함께 찾는다.
- 폭력도: 없음 / 난이도: 낮음

#### 3.6.2 삼국의 불교 유물 비교
- §1의 "유물 비교·추론 활동"을 신라 불상까지 더한 3자 확장판. 별도 신규 메커닉보다 기존 활동의 심화 버전.
- 폭력도: 없음 / 난이도: 중간(3자 비교는 근거 카드 구조가 복잡해짐)

#### 3.6.3 한강 유역 쟁탈
- 지배권이 백제(4세기) → 고구려(5세기) → 신라(6세기) 순으로 이동한 이유(평야·교통·대중국 교역로)를 지리적 근거로 재구성. 전투 장면 없이 "왜 이 땅이 중요했는가"에 집중.
- 폭력도: 없음(전략적 판단 프레임) / 난이도: 중간

#### 3.6.4 살수대첩 ⚠️ 각색 전제 필요
- 을지문덕의 거짓 항복·유인 전술이 핵심이나, 원자료의 사상자 규모(30만 중 2,700명 생환)가 매우 참혹함.
- 전투·사상자 수는 다루지 않고 "적은 병력으로 정보를 활용해 이긴 전략적 판단"으로 한정해야 사용 가능.
- 폭력도: 원자료 높음(각색 필수) / 난이도: 중간

#### 3.6.5 삼국통일 — 계백과 관창 🚫 보류 권장
- 16세 소년 관창의 희생이 신라군 사기를 끌어올렸다는 서사 구조. "아이가 희생해서 이겼다"는 프레임은 폭력 게임화 금지 제약과 정면 충돌 위험이 큼.
- 재현형 협동 MUD로 만들면 죽음을 성취 이벤트로 만들 위험. 다루더라도 전투 재현이 아닌 "사후 기억·기록" 활동으로만 접근 검토.
- 폭력도: 높음(아동 희생 포함) / 이번 후보군에서는 보류 권장

#### 3.6.6 통일신라의 삼국 유민 통합과 발해 건국
- 통일 이후 신라가 고구려·백제·말갈 유민을 흑금서당으로 편성한 사실, 대조영이 고구려 유민 중심으로 발해를 건국한 서사.
- 역할: 고구려 유민 / 백제 유민 / 신라인 / 말갈인 — 다른 배경의 사람들이 하나의 부대·나라를 함께 꾸리는 과정을 협동 결정으로 구성.
- 통합·포용 주제라 폭력 요소가 거의 없고 정서적으로 따뜻한 결말 가능. "유민", "다민족" 등 개념어를 5학년 눈높이로 풀어야 함.
- 폭력도: 없음 / 난이도: 중간

#### 3.6.7 삼국의 예술 비교·대조
- 고분벽화·토기·금관·불상 등을 아우르는 §1 활동의 종합 심화판. 다루는 유물 범위가 넓어질수록 이미지 확보·저작권 확인 부담 증가.
- 폭력도: 없음 / 난이도: 중간~높음

### 3.7 고려시대 묶음

#### 3.7.1 후삼국시대 — "누구를 따를 것인가"
- 견훤(후백제)·궁예(후고구려)·왕건(고려)의 정치 비교. 전쟁 장면 대신 각국 정책 비교에 초점을 맞춰 왜 민심이 왕건에게 모였는지 추론.
- 폭력도: 낮음(정책 비교로 재구성) / 난이도: 중간

#### 3.7.2 고려의 과거제·왕권강화 — "인재를 어떻게 뽑을까"
- 광종의 노비안검법(956)·과거제 도입(958, 쌍기 건의)을 소재로, 호족 자제/평민 인재/시험관 역할이 "왜 과거제가 왕권 강화에 도움이 됐는가"를 추론.
- 완전히 비폭력적이며 제도를 다루는 지적 활동. 개념을 5학년 눈높이로 푸는 작업 필요.
- 폭력도: 없음 / 난이도: 낮음~중간

#### 3.7.3 고려의 발명품 — 청자·직지·화약
- 직지심체요절(1377, 청주 흥덕사, 현존 최고(最古) 금속활자본), 최무선의 화약(화통도감, 진포대첩에서 왜구 방어에 활용)을 소재로 함.
- 협동 MUD보다 §1과 같은 **3자 유물 비교 활동**으로 만드는 게 더 자연스러움. 화약을 다룰 때는 "왜구를 막는 방어 기술" 프레임을 유지하고 전투 묘사는 최소화.
- 폭력도: 낮음(방어적 기술로 프레이밍) / 난이도: 중간

#### 3.7.4 고려의 대외 교역
→ §3.5 벽란도 국제무역과 동일 소재. 중복 제작 방지를 위해 병합.

#### 3.7.5 서희의 담판 ⭐ 최우선 추천
- 993년 거란(소손녕) 침입 시, 서희가 거란의 진짜 목적(고려-송 관계 단절)을 간파해 담판으로 강동 6주(흥화진·용주·통주·철주·귀주·곽주)를 확보한 사례.
- 역할: 지리 정보관(여진이 길을 막는 상황) / 외교 기록관(거란의 진짜 의도) / 국경 수비대(거란 군대 규모·의도, 실제 전투는 없었음) / 서희 역(종합해 협상 논리 구성).
- 전투가 아니라 논리와 정보로 위기를 해결한 실제 사례 — 지금까지 나온 후보 중 폭력 요소가 가장 적으면서도 긴장감은 유지됨.
- 폭력도: 거의 없음(협상으로 위기 해결) / 난이도: 중간(외교 논리를 5학년 눈높이로 단순화하는 작업 필요)

### 3.8 조선말~근대 개항기 묶음

#### 3.8.1 고려말 왕조 교체 — 이성계·정도전·정몽주·이방원
- [위화도 회군(1388)](https://ko.wikipedia.org/wiki/%EC%A0%95%EB%8F%84%EC%A0%84) 이후 정몽주(고려 개혁)와 이방원(새 왕조)의 신념 대립. 시조(하여가/단심가)를 포함한 입장 비교 활동으로 구성.
- 역할별로 각 인물의 시조·입장 카드를 나눠 갖고 "왜 같은 상황에서 다른 선택을 했을까"를 추론. 정몽주의 죽음은 사실관계로만 언급하고 재현하지 않는다.
- 폭력도: 낮음 / 난이도: 중간

#### 3.8.2 경복궁·사대문의 유교적 의미, 창덕궁과의 비교
- 사대문 이름은 [인·의·예·지](https://www.a-ha.io/questions/42fd20ac8e0f8188874e51fcda61c7d9)(흥인지문·돈의문·숭례문·숙정문)를 담았고, [경복궁은 중앙축 대칭 배치, 창덕궁은 자연 지형에 맞춘 비대칭 배치](https://ko.wikipedia.org/wiki/%EC%B0%BD%EB%8D%95%EA%B6%81)로 뚜렷이 대비된다.
- 협동 MUD보다 §1 유물 비교 활동 틀을 건축물에 적용하는 편이 적합.
- 폭력도: 없음 / 난이도: 낮음~중간

#### 3.8.3 조선 전기 유교 신분제(양반·중인·상민·천민)
- [양반(관리)·중인(관청 실무)·상민(농업·수공업·상업)·천민(대부분 노비)](https://contents.history.go.kr/mobile/ta/view.do?levelId=ta_e71_0010_0030_0020_0020)으로 구성된 신분 구조.
- 신분 역할극으로 만들면 불평등 체험이 될 위험이 있어, 각 신분의 하루를 나란히 놓고 비교·관찰하는 활동으로 접근하는 편이 안전하다.
- 폭력도: 낮음(톤 설계 주의) / 난이도: 중간

#### 3.8.4 훈민정음과 세종 시대 과학 기구
- [혼천의·자격루·앙부일구·측우기](https://contents.history.go.kr/mobile/eh/view.do?levelId=eh_r0260_0010&code=eh_age_30) 등 장영실이 다수 제작한 기구들.
- §3.4 훈민정음 창제 후보에 과학 기구 역할(혼천의 담당/자격루 담당/측우기 담당)을 더한 확장판으로 구성 가능. 원리는 수원 화성 사례처럼 생활 비유로 단순화.
- 폭력도: 없음 / 난이도: 중간

#### 3.8.5 임진왜란 — 이순신, 의병
→ §3.1 한산도 해전 후보와 동일 계열. 의병 활동을 더하면 "수군만이 아니라 백성도 함께 싸웠다"는 협동 서사로 확장 가능. 폭력도는 기존과 동일하게 중간(전술 중심 완화 필요).

#### 3.8.6 병자호란 — 남한산성
- [인조가 남한산성에서 45일 항전하다 항복, 삼전도에서 굴욕을 당함](https://namu.wiki/w/%EB%B3%91%EC%9E%90%ED%98%B8%EB%9E%80). 주화파(화친)와 척화파(항전)의 대립이 핵심 갈등.
- 전투 재현이 아니라 "항전이냐 화친이냐" 딜레마 자체를 게임 메커닉으로 구성. 역할: 척화파 신하(명분) / 주화파 신하(식량·군사력 부족) / 백성 대표(추위·굶주림) / 인조 역(종합 결정).
- 실제 항복이라는 결과를 "패배"가 아니라 "당시 조건에서의 불가피한 선택"으로 재구성한다.
- 폭력도: 낮음(의사결정 중심) / 난이도: 중간

#### 3.8.7 조선 후기 서민문화 (풍속화·판소리·탈춤·한글소설)
- [김홍도(서민 생활)·신윤복(양반 풍류)·판소리·탈춤(양반 위선 풍자)](https://contents.history.go.kr/mobile/eh/view.do?levelId=eh_r0314_0010) — 경제 발전과 함께 서민 문화가 확대된 시기.
- 협동 MUD보다 유물(그림) 비교 활동에 적합 — 김홍도 vs 신윤복 풍속화를 비교하며 "이 그림은 누구의 시선인가" 추론.
- 폭력도: 없음 / 난이도: 낮음~중간

#### 3.8.8 영·정조의 탕평책, 정약용과 실학
→ §3.2 수원 화성 축성 후보와 동일 시대·인물. [탕평책(당파 균형)](https://ko.wikipedia.org/wiki/%ED%83%95%ED%8F%89%EC%B1%85)이라는 정치적 배경을 수원 화성 시나리오의 도입부 설명으로 병합하는 것을 제안.

#### 3.8.9 개항 — 강화도 조약 ⚠️ 톤 설계 주의
- [1875년 운요호 사건을 일본이 계획적으로 일으켜 무력시위를 벌였고, 1876년 강화도 조약이 체결](https://contents.history.go.kr/mobile/kc/view.do?levelId=kc_i400800&code=kc_age_40)됨(불평등 조약).
- 근현대와 맞닿은 민감 주제라 "재미있는 협동"보다 **기록·기억 중심** 접근이 제약에 맞음. 조약 내용을 학생이 직접 읽고 "왜 불평등한가"를 스스로 찾아내는 자료 분석 활동을 우선 검토.
- 폭력도: 물리적 폭력은 적으나 정치적 민감도 높음 / 톤 설계가 콘텐츠보다 어려움

#### 3.8.10 근대 문물 도입과 오늘날 비교
- [1899년 경인선 개통, 한성전기회사의 전차·전등, 1884년 우정총국(우편)](https://contents.history.go.kr/mobile/ta/view.do?levelId=ta_h31_0070_0010_0040) 등.
- 협동 MUD보다 "그때와 지금" 비교 활동에 적합 — 전차→지하철, 우정총국→택배 앱처럼 과거·현재를 짝짓는 활동.
- 폭력도: 없음 / 난이도: 낮음 (협동 MUD 메커닉보다 비교 활동 유형에 더 적합)

## 5. 남은 질문 / 다음 단계

- 커리큘럼 순서(선사~삼국~통일신라·발해~고려~조선~근대)에 가까운 소재부터 제작한다는 원칙에 따라, **서희의 담판**·**시조 설화**·**병자호란(딜레마형)**이 다음 구체화 후보로 유력하다.
- 고려의 몽골·원·요 침입(서희 담판 이후의 후속 침입들)은 아직 개별 조사하지 않음.
- 근대 이후(일제강점기~광복 이후)는 이번 브레인스토밍 범위 밖이며, "기록·기억 중심" 제약이 더욱 강하게 적용될 영역이므로 별도로 신중히 접근한다.
- 모든 후보는 §2의 자리 이동형 Room 운영 모델(3~5인 가변 인원, QR 입장, 배정/탐사 시작 분리) 위에서 소재만 교체하는 것을 전제로 하며, 실제 다중 iPad 배포에는 별도 Supabase·Vercel 연결이 필요하다(기존 결정 사항, 미변경).
- ⚠️/🚫 표시 항목은 구현 착수 전 반드시 사용자 재확인을 받는다.
