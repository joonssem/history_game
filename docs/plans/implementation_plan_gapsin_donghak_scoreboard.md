## 2. 신분 흐름

```
시작: 중국어 능력자(zh) / 일본어 능력자(ja)  [3,000p, 능력은 끝까지 보존]
 └ EP2 역관 시험 → 영선사(zh) / 수신사(ja)
    └ EP7 제비뽑기 → 명성황후파 / 흥선대원군파
       └ EP16 → 온건개화파 / 급진개화파
          ├ 급진 → EP22 농민(급진개화파(농민)) ─ EP31 → 동학농민군
          └ 온건 → EP22 지방 관리 ───────────── EP31 → 관군
```
- EP16 신분 결정: 흥선대원군파는 `왼쪽 남자`(김윤식) → 온건, `오른쪽 남자`(김옥균) → 급진. 명성황후파는 제비뽑기 E → 온건, F → 급진. 모두 +20.
- EP7 제비뽑기: **C → 흥선대원군파(−100), D → 명성황후파(+100)** (좌표 확정: C 열 x=142 ↔ 흥선대원군파 결과 x=52).
- EP22: 급진은 '농민'이 된 뒤 선택(S97), 온건은 선택 후 '지방 관리'가 된다(S100).
- EP31(상황): 농민 +300 → 동학농민군, 지방 관리 −400 → 관군.

## 5. 종이 점수표의 나머지(마무리 화면)

- **한줄 정리하기 9개**: 정의가 인쇄돼 있고 학생이 낱말을 쓴다(영선사, 수신사, 별기군, 임오군란, 온건 개화파, 급진 개화파, 갑신정변, 동학농민운동, 청일 전쟁). 앱: 정의 표시 + 낱말 입력 + '정답 보기'.
- **온건·급진 개화파 입장 정리**: 빈칸 4개(`( )처럼 천천히 개화하자` / `조선은 힘이 약하니 청나라에 ( )` / `법과 제도는 우리 전통대로` / `서양의 ( )만을 받아들이자`). 보기: 나라 전체·의존하자·청나라·일본·기술·벗어나자(S71~72, 교과서 26쪽). 종이표에는 온건 칸만 있다.
- 수업 중 화면 활동(S70~73, S81~94, S130~133, S145)은 점수와 무관한 교과서 확인이라 앱에 넣지 않는다.

## 6. 구현 방침(제안)

1. `cooperative-mud/gapsin-donghak-scoreboard/`(가칭)에 `game.js`·`app.js`·`index.html`·`board.css`. 세도정치 점수판의 **기록 재계산(derive)** 구조를 그대로 쓴다.
2. 엔진 확장: ①단일 `role`(복귀 없음) + 불변 `ability`, ②플래그(농업기술·사격기술·전창혁), ③선택지의 `bonus: {ability, delta}` 자동 추가, ④국력 💀/♥ 누적(5칸 상한), ⑤상황 장면의 신분 전환(EP31), ⑥신분별로 다른 선택지, ⑦주관식(EP2).
3. 점수표 화면은 종이표와 같은 열(현재 신분·나의 선택·획득·손실·남은 포인트)에 CHAPTER 구분을 넣고, 국력 막대(💀 5칸/♥ 5칸)와 가이드를 위에 둔다.
4. 검증: 세도정치와 같이 ①PPT 좌표 자동 대조 스크립트(`crosscheck`) ②손계산 대조 규칙 테스트 ③Chrome 헤드리스 e2e(양반 격인 경로 여러 개: 영선사→명성→온건→지방관리→관군, 수신사→흥선→급진→농민→동학농민군 등).

## 7. 사용자 판단이 필요한 지점

1. **국력 가이드의 뜻**: 종이표 가이드가 아이콘만 있고(`💀 > ♥`, `💀 < ♥`, `💀 FULL`) 해석 문장이 PPT에 없다. 앱에 해석(예: 엔딩 문구)을 넣을지, 비교 기호만 보여 줄지.
2. **트로피 공개 방식**: S157에서 교사가 '개인 보상'을 공개한다. 앱이 최종 점수만 보여 주고 학생이 '내 개인 보상 보기'를 눌러 등급을 보게 할지, 앱에서는 숨길지.
3. **EP2 주관식**: 정답을 앱에 입력해 자동 채점할지(철자·띄어쓰기 오류 위험), 교사가 정답을 말한 뒤 학생이 '정답/오답'을 누르게 할지(권장).
4. **EP38 동학농민군**: S148은 "협조하지 않으면 가지고 있는 **모든** 포인트를 잃을 수도 있다"고 하지만 결과는 −3,000이다. PPT 결과(−3,000)를 따를 예정.
5. **능력 추가 점수 자동 적용**: `원래 중·일본어 능력자 추가 ±50`을 학생이 누르지 않고 앱이 처음 능력으로 자동 적용(권장). EP8도 '원래 능력' 선택지는 눌러서 고르되 내 기록을 힌트로 보여 줄 예정.
6. **EP22 급진개화파(농민) 신분 표기**: 선택 전에 신분이 농민이 되는데, 앱은 선택을 누른 뒤 신분을 바꾼다(표의 현재 신분은 급진개화파로 남는다). 선택 전 즉시 바꾸는 쪽이 필요하면 알려 달라.
