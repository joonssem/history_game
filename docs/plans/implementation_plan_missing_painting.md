# 구현 계획 — 사라진 그림을 찾아라(서민 문화 추리 게임)

- 상태: 진행 중(2026-11-04) — 1차 구현·자동 흐름 검증 완료, 미커밋 아님(커밋 후 갱신)
- 위치: `cooperative-mud/missing-painting/` (협동 mud 허브에 카드, D-047 방침: 허브에 두고 추이를 본다)
- 원본: 교사의 2019년 6학년 오프라인 "서민 문화 추리 게임"(HWP 5 + PDF 3, 저장소 밖). 노트정리(빈칸 채우기) → 12개 스테이션 추리 게임 → 추리 조각 12글자를 맞춰 인물 추리(허난설헌).

## 사용자 결정 (2026-11-04)
1. 교과서에 없는 내용(신윤복, 춘향가 사랑가, 하회탈, 봉산탈춤 등)은 그대로 유지.
2. 신체 표현형(삼행시, 사랑가, 탈 표정, 김홍도 따라하기)은 기기 방식으로 바꾼다 → 삼행시는 첫 글자·길이 자동 점검, 사랑가·탈 표정은 "모둠이 해 봤어요" 체크 + 가사 빈칸, 김홍도 따라하기는 민화 미션으로 대체.
3. 현행 교과서 100~103쪽에 맞춰 민화 미션 추가(12개를 유지하려고 미션 12를 교체).
4. 이미지는 저작권 때문에 원본 사진·그림을 쓰지 않고 직접 그린 SVG(하회탈 3, 달, 사자 탈)와 검색 안내로 대체. 학생이 iPad로 스스로 검색한다.

## 구조
- `quest.js`: 미션 12개(part 종류 text/distinct/pick/acrostic/confirm), 추리 조각 글자, 정답 문장, 공개 문구, 돌아보기 문항, 교사 확인 숫자(1700).
- `app.js`: 소개 → 미션 목록(순서 자유) → 미션 → 추리 조각 맞추기 → 인물 공개 → 돌아보기 → 완료. `localStorage` 키 `history_cooperative_missing_painting_v01`, 이름·학번 입력 없음.
- 교사 확인 숫자는 막힌 모둠을 넘기는 탈출구로만 쓴다(미션별 접이식).
- 정답 근거는 교사의 정답 HWP. 미션 10은 144kg×300×2500원=108,000,000원으로 재계산해 확인했다.

## 확인·남은 일
- 허난설헌이 "그림을 그린" 인물이라는 설정은 교사 설계다. 공개 문구는 "뛰어난 시로 이름이 높았다"까지만 쓰고 그림 솜씨는 단정하지 않았다.
- 서당 갓(장가를 갔기 때문)과 월하정인 월식은 널리 알려진 해석이다. 학생 안내 문구에서 단정을 피할지 사용자가 판단한다.
- 하회탈 SVG의 선비/각시/양반 구별이 학생에게 충분한지 수업 전 확인한다. 미션 7 힌트에 검색 안내가 있다.
- iPad 실기 확인과 수업 관찰은 날짜 미정.
