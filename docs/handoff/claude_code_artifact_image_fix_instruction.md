# Claude Code 작업 지시서 — 유물 아이콘·보상 토스트 수정

## 승인 범위

사용자가 유물 이미지 정합성 보고서의 수정안을 승인했다. 다음 항목을 직접 수정한다.

### 아이콘 수정 대상

- `art_3`: 모아이 석상 아이콘을 고인돌을 더 잘 나타내는 돌·석조 계열 아이콘으로 교체
- `art_6`: 팔레트·그림 아이콘을 비석 계열 아이콘으로 교체
- `art_10`: 배 아이콘을 합격증·문서 계열 아이콘으로 교체
- `art_11`: 동전 아이콘을 풍속화·탈 계열 아이콘으로 교체
- `art_12`: 지도 아이콘을 판옥선·화포 계열 아이콘으로 교체
- `art_13`: 두루마리 아이콘을 엽전·동전 계열 아이콘으로 교체
- `art_deep_2`: 활 아이콘을 검·묘지석을 나타내는 계열 아이콘으로 교체

유니코드에 정확한 한국 유물 아이콘이 없는 경우, 가장 덜 오해를 부르는 이모지를 선택한다. 기존 유물과 불필요한 중복이 생기면 대안을 비교하고 최종 선택을 보고한다.

### 보상 토스트 수정 대상

- `js/mudEngine.js`의 MUD 완료 보상 토스트에서 `art_1` 같은 raw `artifactId`가 표시되지 않도록 한다.
- `data/artifacts.json`에서 해당 ID의 사람이 읽는 `name`을 찾아 토스트에 표시한다.
- 도감 경로(`js/storyEngine.js`)와 MUD 경로의 토스트 표시가 동일한 유물명 결과를 내야 한다.
- 유물 ID를 찾지 못하는 예외 상황에는 안전한 fallback을 유지하되, 정상 데이터에서는 반드시 유물명이 표시되어야 한다.

## 변경 금지

- 유물 `name`, `era`, `tier`, `tierName`, `desc`, `category`, `hint`는 수정하지 않는다.
- MUD의 `artifactId`, 보상명, 단계 구조, `simulator.scene`, `hotspots`, `interaction`, `completion.target`은 수정하지 않는다.
- 아이콘 변경을 이유로 학습 문구나 역사 설명을 바꾸지 않는다.
- 새로운 이미지 자산·패키지·프레임워크를 추가하지 않는다.

## 검증

1. `data/artifacts.json` JSON 검증
2. MUD 보상 ID·이름 연결 무결성 검증
3. 도감 카드에서 수정된 7개 아이콘을 육안 확인
4. `regular_paleolithic`, `regular_bronze_age`, `regular_gojoseon`, `regular_gwangbok`, `regular_japanese_rule_2` 중 대표 MUD 완료 보상 토스트 확인
5. 토스트에 `art_1`, `art_3` 같은 raw ID가 표시되지 않고 유물명이 표시되는지 확인
6. `node --check js/mudEngine.js`
7. 기존 데이터·MUD 검증 스크립트 실행
8. 콘솔 오류 및 도감 렌더링 오류 확인

## 보고·커밋

보고서에 다음을 포함한다.

- 최종 아이콘 매핑표와 선택 이유
- 수정 파일과 변경 범위
- 보상 토스트 전후 표시 결과
- 실행한 검증 명령과 결과
- 기존 유물·보상 연결 회귀 여부

검증 통과 후 Claude가 Phase 단위로 직접 커밋한다. push는 사용자 승인 상태이므로 진행해도 된다. Codex 담당 문서나 무관한 파일은 수정하지 않는다.
