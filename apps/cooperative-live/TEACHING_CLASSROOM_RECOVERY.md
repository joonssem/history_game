# 교사 모둠 진행·부족 인원 복구 안내

이 기능은 교사가 수업 진행을 복구하는 도구다. 아직 격리 브랜치 구현이며 실제 수업 전에는 해당 프런트·Convex 함수와 스키마가 함께 배포된 Preview에서 인증과 기기 리허설을 확인한다.

## 입장·재접속

1. 같은 탭은 먼저 새로고침한다. QR·수업 코드 재시도는 같은 좌석으로 연결되고 중복 참가자를 만들지 않는다.
2. 저장 정보나 기기를 잃으면 교사가 기존 좌석에서 `자리 다시 연결` 코드를 발급한다. 학생은 수업 코드와 12자리 코드를 입력한다. 개별 전달·5분 만료·1회용이며 이전 학생 토큰은 무효화된다.
3. 정상 활성 학생의 재접속은 호·역할·진도·초안 확인을 유지한다. 제외했던 학생이 돌아오면 기존 역할을 유지하면서 공동 초안을 다시 열고 모두 새 초안을 확인한다.

서로 다른 기기가 각기 처음 만든 접속이 같은 실제 학생인지는 자동 식별하지 않는다. 학생 계정·이름을 추가 수집하지 않으므로 해당 경우는 교사가 기존 좌석을 확인한다.

## 모둠 상태·도움 요청

- 모둠 카드에서 현재 단계, 최초 판단·자료 설명·초안 확인·개인 완료의 수와 막힌 이유를 확인한다.
- 학생이 도움을 요청하면 모둠을 확인하고 기존 `힌트`를 보내거나 아래 교사 진행을 사용한다. 조치가 끝났을 때 `도움 요청 해결 완료`를 누른다. 힌트 전송만으로 도움 요청을 자동 종료하지 않는다.
- 일시정지 중에는 교사 단계 이동과 복구 모드를 실행할 수 없다. 학생 설명을 들은 뒤 재개한다.

## 교사 한 단계 진행

1. 해당 모둠의 학생들과 다음 단계 진행에 동의했는지 확인한다.
2. `교사 한 단계 진행`을 누르고 모둠·현재 단계·다음 단계를 확인한다.
3. 사유를 선택하고 학생 동의를 확인한 뒤 실행한다. 한 번의 실행은 해당 모둠만 한 단계 이동한다.
4. 공동 초안이 없으면 초안·확인 단계를 건너뛸 수 없다. 먼저 학생이 두 주제, 서로 다른 두 역할 근거, 자료 한계와 연결 설명으로 유효한 초안을 저장한다.
5. 개인 판단·설명·초안 동의는 교사가 대신 완료하지 않는다. 교사 진행으로 마침 단계에 도달해도 개인 미완료가 그대로 남는다. 최근 진행 이력은 모둠 카드에서 확인한다.

현재 단계나 초안이 바뀌면 오래된 확인 창의 요청은 거부된다. 창을 취소하고 모둠의 최신 상태로 다시 실행한다.

## 1~2명만 남은 모둠

새 모둠의 시작 편성은 기존 3~5명이다. 수업 도중 인원이 부족하면 다음과 같이 처리한다.

1. 재접속을 먼저 시도하고, 실패하면 해당 모둠에서 `부족 인원 복구 모드`를 켠다. 학생 확인·사유·동의 절차를 거친다.
2. 접속하지 못한 참가자를 교사가 확인해 제외한다. 최근 응답이 늦다는 이유만으로 자동 제외하지 않는다. 마지막 학생까지 제외할 수는 없다.
3. 잔류 학생은 원래 역할로 진행한다. 공동 초안 단계에는 빠진 **원래 배정 역할의 근거 요약**이 표시된다. 비공개 본문이나 원래 배정되지 않은 역할은 공개되지 않는다.
4. 두 역할 근거와 자료 한계 조건은 유지한다. 1명도 자기 역할과 보충 요약을 연결해 공동 설명을 만들며, 실제 잔류 학생이 최신 초안을 확인한다.
5. 돌아온 학생은 기존 좌석을 복구한다. 인원이 다시 바뀌면 모두 초안을 다시 확인한다.

네트워크 복구나 자료 이해가 어렵다면 기존 교사 진행형·종이 대체안으로 전환한다. 기술 복구 모드의 1인 활동이 실제 모둠 협력과 같은 교육적 효과를 낸다고 가정하지 않는다. 실제 완료 시간과 교사 개입은 현장 관찰에서 기록한다.

## 리허설에 추가할 확인

- [ ] QR 연속 사용과 응답 재시도가 추가 좌석을 만들지 않는다.
- [ ] 3인에서 2인·1인으로 줄어도 명시 복구 뒤 초안·확인을 마칠 수 있다.
- [ ] 빠진 역할의 요약만 표시되고 비공개 본문은 표시되지 않는다.
- [ ] 교사 진행 후 개인 미완료 수와 다른 모둠 상태가 유지된다.
- [ ] 제외 학생 복귀 시 초안이 다시 열리고 이전 확인은 무효화된다.
- [ ] 도움 요청·힌트·조치·해결 완료를 교사가 수행할 수 있다.
- [ ] 종료 시 교사 진행 이력과 세션 하위 데이터가 삭제된다.
