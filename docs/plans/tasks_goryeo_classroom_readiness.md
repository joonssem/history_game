# 고려 건국·고려 문화 협동 수업 운영 체크리스트

- 작성일: 2026-09-30
- 작업: `TASK-20260930-GORYEO-CLASSROOM-READINESS`
- 상태: `운영 대체안·체크리스트 및 실시간 구현·자동 검증 완료 · 교실 현장 실행 대기`
- 계획: [`implementation_plan_goryeo_classroom_readiness.md`](./implementation_plan_goryeo_classroom_readiness.md)

## A. 다음 수업 전 공통 준비

- [ ] 각 활동에 15분 배정. 10분만 있으면 계획서의 축약 흐름을 사용한다.
- [ ] 실시간 협동 앱을 기본 경로로 안내하지 않는다. 학생 로그인이 없어도 수업이 진행되게 한다.
- [ ] 3~5명 모둠을 편성하고 모둠 번호만 칠판이나 화면에 제시한다.
- [ ] 모둠 기록지를 활동별 한 장씩 준비하고 펜·화이트보드 또는 발표 화면을 준비한다.
- [ ] 개인 판단·학생 이름·대화 원문은 수집하지 않는다고 안내한다.
- [ ] 기기·인터넷이 작동하지 않아도 교과서 또는 인쇄 자료로 전환할 준비를 한다.

## B. 고려의 건국 — 교사 진행형 협동 대체안

- [ ] 교사용 안내의 다섯 관점(신라계 귀족, 후백제 지역 농민, 발해 유민, 지방 호족, 고려 관리 지망생)을 카드나 교사 낭독으로 제시한다.
- [ ] 5인 모둠은 관점 하나씩 맡긴다. 3~4인 모둠의 빠진 관점은 공통 자료로 둔다. 한 학생에게 두 관점을 맡기지 않는다.
- [ ] 학생이 친구 의견을 듣기 전에 우선 정책 하나를 고르게 한다.
- [ ] 한 사람씩 자기 관점을 말하고, 모둠이 정책 2개를 고르게 한다.
- [ ] 서로 다른 관점의 근거 2개와 자료의 한계 1개를 기록한다.
- [ ] 15분 운영을 시작해 단계별 실제 시간을 간단히 기록한다.
- [ ] 발표에서 모든 관점이 고려됐는지 확인한다.

## C. 고려의 문화와 사람들의 생활 — 현장 게이트 전 대체 흐름

- [ ] `feat/goryeo-classroom-activities`의 새 실시간 시나리오는 제작·자동 검증됐지만, 현장 리허설 전에는 학생용으로 안내하지 않는다.
- [ ] 기기를 쓰면 기존 `regular_goryeo_culture`를 근거 탐색 자료로 사용한다. 접속이 불안정하면 교사 화면이나 인쇄 자료를 쓴다.
- [ ] 기존 MUD만으로 가족·상속·신분·생업까지 다뤘다고 간주하지 않는다.
- [ ] 생활 모습까지 포함하려면 교과서 또는 출처 확인이 끝난 생활 자료를 최소 하나 준비한다. 준비하지 못하면 질문 범위를 문화유산·기술·신앙·교류·자료 한계로 좁힌다.
- [ ] 만든 사람, 사용한 사람, 신앙·사회 목적, 생활 자료, 자료 한계 렌즈를 모둠원에게 나눈다.
- [ ] 각자 근거 하나를 말하고 모둠이 자료 2개를 연결한 주장과 자료 한계를 완성한다.
- [ ] 15분 운영을 시작해 완료 시간·막힌 용어·교사 개입을 익명으로 기록한다.

## D. 수업 중 공통 관찰

- [ ] 각 모둠원이 근거나 관점을 한 번 이상 말했는가?
- [ ] 공동 주장이 서로 다른 자료·관점 2개에 연결됐는가?
- [ ] 자료로 알 수 없는 점을 모둠이 구분했는가?
- [ ] 완료 시간, 막힌 단계, 교사 개입 횟수를 식별 정보 없이 기록했는가?

## E. 수업 뒤

- [ ] 실제 단계별 시간을 활동별로 기록하고 예상값과 구분한다.
- [ ] 학생 이름·학번·개인 답·대화 원문은 기록하지 않는다.
- [ ] 결과를 `EXPERIMENTS.md`의 관찰 → 가설 → 결과 → 다음 결정 형식으로 남긴다.
- [ ] 한 번의 운영만으로 일반적 효과를 확정하지 않는다.

## F. 고려 건국 실시간판 재개 — 전 항목 필수

- [ ] 복구 기능 브랜치 통합과 배포 상태를 확인한다.
- [ ] Auth0 callback 문제를 해결하고 교사 로그인·세션 생성·학생 입장을 확인한다.
- [ ] 교사 1명 + 4~8대에서 QR·수동 입장, 탭 종료·자리 복구, 학교 Wi-Fi 단절·복귀를 확인한다.
- [ ] 중복 완료 탭, 참가자 제외·복원, 서로 다른 모둠의 독립 진행을 확인한다.
- [ ] 공동 초안 수정 뒤 이전 확인이 무효화되고 최신 revision 전원 확인을 요구하는지 확인한다.
- [ ] 힌트·심화 이력, 학생 확인 표시, QR 확대, 종료 삭제를 확인한다.
- [ ] 전체 리허설이 8~10분 안에 끝나고 개인 식별 정보가 저장되지 않는지 확인한다.
- [ ] 하나라도 실패하면 전체 학급 실시간 운영을 보류하고 교사 진행형 대체안을 쓴다.
- [ ] 성인 리허설 통과 뒤 학생 3~5명 소규모 관찰을 거쳐 다음 운영을 결정한다.

## G. 고려 문화 실시간판 수업 사용 전

- [ ] 공통 실시간 복구 게이트를 통과했는지 확인한다.
- [x] 3·4·5인 편성과 3인 공통 직지 자료를 자동 회귀로 확인한다.
- [x] 청자·가족 상속 기록·대장경·직지 자료와 과잉 일반화를 막는 한계를 포함한다.
- [x] 공개 역할 이름과 서버 전용 비공개 자료를 분리하고 출처를 등록한다.
- [x] 앱 자동 검사 전체 통과: lint, TypeScript, 단위 21건, Convex 7건, production build.
- [ ] 4~8대 리허설 뒤 학생 파일럿에서 8~10분 진행과 이해도를 확인한다.
- [ ] 학생이 막히면 문장·역할·단계를 특정하고 최소 수정한다.
- [ ] 개인정보 운영 근거·실제 배포 환경을 확인하고 교사 Go 판정을 기록한다.

## 종료 기준

- 교사 진행 대체 흐름은 두 활동에서 모둠 공동 주장·근거·자료 한계를 실행할 수 있을 때 사용할 수 있다.
- 고려 건국 실시간판은 F 전체와 소규모 학생 시험 전까지 전체 학급 사용을 재개하지 않는다.
- 고려 문화 실시간판은 G의 현장 검증과 교사 Go 판정 전까지 수업 사용 가능으로 표시하지 않는다.
