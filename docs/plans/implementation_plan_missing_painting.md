# 구현 계획 — 사라진 그림을 찾아라(서민 문화 추리 게임)

- 상태: 진행 중(2026-11-04) — 1차 구현·자동 흐름 검증 완료, 미커밋 아님(커밋 후 갱신)
- 위치: `cooperative-mud/missing-painting/` (협동 mud 허브에 카드, D-047 방침: 허브에 두고 추이를 본다)
- 원본: 교사의 2019년 6학년 오프라인 "서민 문화 추리 게임"(HWP 5 + PDF 3, 저장소 밖). 노트정리(빈칸 채우기) → 12개 스테이션 추리 게임 → 추리 조각 12글자를 맞춰 인물 추리(허난설헌).

## 사용자 결정 (2026-11-04)
1. 교과서에 없는 내용(신윤복, 춘향가 사랑가, 하회탈, 봉산탈춤 등)은 그대로 유지.
2. 신체 표현형(삼행시, 사랑가, 탈 표정, 김홍도 따라하기)은 기기 방식으로 바꾼다 → 삼행시는 첫 글자·길이 자동 점검, 사랑가·탈 표정은 "모둠이 해 봤어요" 체크 + 가사 빈칸, 김홍도 따라하기는 민화 미션으로 대체.
3. 현행 교과서 100~103쪽에 맞춰 민화 미션 추가(12개를 유지하려고 미션 12를 교체).
4. 이미지는 저작권 때문에 원본 사진·그림을 쓰지 않고 직접 그린 SVG(달, 사자 탈)와 검색 안내로 대체. 학생이 iPad로 스스로 검색한다.

## 구조
- `quest.js`: 미션 12개(part 종류 text/distinct/pick/acrostic/confirm), 추리 조각 글자, 정답 문장, 공개 문구, 돌아보기 문항, 교사 확인 숫자(1700).
- `app.js`: 소개 → 미션 목록(순서 자유) → 미션 → 추리 조각 맞추기 → 인물 공개 → 돌아보기 → 완료. `localStorage` 키 `history_cooperative_missing_painting_v01`, 이름·학번 입력 없음.
- 교사 확인 숫자는 막힌 모둠을 넘기는 탈출구로만 쓴다(미션별 접이식).
- 정답 근거는 교사의 정답 HWP. 미션 10은 144kg×300×2500원=108,000,000원으로 재계산해 확인했다.

## 확인·남은 일
- 허난설헌이 "그림을 그린" 인물이라는 설정은 교사 설계다. 공개 문구는 "뛰어난 시로 이름이 높았다"까지만 쓰고 그림 솜씨는 단정하지 않았다.
- 서당 갓(장가를 갔기 때문)과 월하정인 월식은 널리 알려진 해석이다. 학생 안내 문구에서 단정을 피할지 사용자가 판단한다.
- 하회탈 SVG의 선비/각시/양반 구별이 학생에게 충분한지 수업 전 확인한다. 미션 7 힌트에 검색 안내가 있다.
- iPad 실기 확인과 수업 관찰은 날짜 미정.

## 진행 기록
- 2026-11-04 1차 구현: 12개 미션 전체 흐름(오답·힌트·조각 퍼즐·공개·돌아보기·새로고침 저장)을 headless Chrome으로 검증했고, 폰 폭 화면(미션 목록, 미션 7)을 확인했다.
- 2026-11-04 정서 수정(사용자 지시): 1번 간에 좋은 음식 → 판소리 <흥부가>, 정답 제비. 2번 삼행시 → 김홍도·신윤복 그림 제목 검색 입력(이 활동 미션지에 나온 서당·벼 타작·미인도·월하정인은 안내 후 불인정). 4번 사랑가 → 수궁가 ‘범 내려온다’(이날치 밴드) 연계, 정답 수궁가·호랑이 + 청취 체크. 6번 보티첼리 → 윤두서 자화상(국보 제240호) 검색. 7번 표정 따라하기 삭제. 10번 힌트 삭제. 11번 실학자 1명. 12번 민화 → 구글 ‘모두의 풍속도 2026’ 검색해 모둠원이 1개씩 이미지 찾기(자유 서술 한 줄 + 체크). 3·5·8·9번은 그대로.
- 정답 근거: 윤두서 자화상 국보 제240호(검색으로 확인). 이날치는 조선 후기 명창(1820~1892) 이름에서 따온 밴드이고 ‘범 내려온다’는 수궁가 사설 바탕(검색 기사). 풍속화 제목 허용 목록은 단원풍속도첩(보물 제527호)·혜원전신첩(국보 제135호)의 널리 알려진 작품명으로 만들었고 전체 목록과 대조하지는 못했다. 목록에 없는 정답 제목은 quest.js의 accept에 추가한다.
- 미확인: ‘모두의 풍속도 2026’은 웹 검색으로 찾을 수 없었다. 지시대로 구글 검색 안내로만 쓰고, 검색이 안 되면 12번을 막히게 하지 않도록 교사 확인 숫자 출구가 있다. 교과서 민화(101쪽) 미션은 이번 수정으로 빠졌고 돌아보기 선택지에만 남았다.
- 2026-11-04 미션 7 변경(사용자 지시): 하회탈 그림 선택을 없애고, 하회별신굿탈놀이에서 지금은 전해지지 않는 탈 3개(총각·별채·떡다리) 이름을 검색해 적는 문제로 바꿨다. 하회탈 SVG 3개는 삭제. 검색으로 세 탈이 현존하지 않는다는 점은 확인했으나 ‘탈 14종 중 3개 분실’이라는 수치는 확인하지 못해 학생 문구에 쓰지 않았다.
