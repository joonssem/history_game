# Regular MUD 시뮬레이터 이미지 전수조사

> 읽기 전용 조사 문서. `data/mud/regular_*.json` 28개 전체, 215개 스테이지를 대상으로 했다. 편집한 파일 없음.

## 0. 조사 방법과 한계

- **"이미지"의 실체**: 이 프로젝트에는 이미지 파일이 하나도 없다. 모든 시뮬레이터 그림은 `js/mudSimulators.js`의 `drawConfiguredSceneBackground(ctx, w, h, scene)` 함수(977줄, scene 분기 104개)가 Canvas로 직접 그린다. 각 스테이지는 JSON에 `simulator.scene`(전용 삽화 104종 중 하나) 또는 `simulator.mode`(scene 미선언 시 뜨는 범용 레거시 그래픽 22종) 중 하나를 선언하며, `simulator.hotspots`가 있으면 공용 핫스팟 렌더러가 scene/mode보다 우선한다.
- **설명 작성 방식**: 각 scene 분기의 Canvas 도형(좌표·색상·`fillText`)을 직접 읽어 무엇을 그리는지 서술했다. 일부(황산벌·매소성·천문령 3곳)만 화면에 실제 한글 캡션(`fillText`)이 있고, 나머지 94곳은 캡션 없이 도형만으로 구성돼 코드 판독으로 설명을 작성했다. 코드에 남은 설계 의도 주석(예: "신체 훼손 연상 방지", "진압·부상 장면 없이")이 있는 경우 그대로 반영했다.
- **한계**: 실제 렌더링 스크린샷으로 대조 검증하지는 않았다(97종 전수 스크린샷은 이 조사 범위 밖). 좌표·색상 판독에 기반한 서술이므로 세부 비례는 실제 화면과 다소 다를 수 있다.
- **narrative 발췌**는 80자로 잘랐다(전체 서사 대조는 원본 JSON 참고). choices는 원문 그대로다.

## 3. 요약 관찰

- 97개 scene 중 실제 화면에 한글 캡션 텍스트가 뜨는 것은 3개(`hwangsanbeol-battle`/`maesoseong-defense`/`cheomunryeong-battle`, 모두 통일신라~발해 전환기 3파전 계열)뿐이고, 나머지 94개는 순수 도형·색상 구도로만 시대를 표현한다.
- 근현대사 민감 주제(6·25, 의병, 독립운동, 광주 등) scene에는 코드 주석으로 남은 명시적 설계 원칙이 반복된다 — 군인·무기·폭력 묘사 금지, 남북/양측 동일 색상, 특정 인물 영웅화 대신 동일 크기 실루오 군중 배치, 신체 훼손 연상 회피. 표1에 이 원칙이 반영된 설명을 그대로 남겼다.
- `hasHotspots` 스테이지(주로 자료 해석·판단형)는 전용 배경 그림이 없고 핫스팟 좌표에 라벨 텍스트만 얹힌 상태다 — 표1의 화려한 전용 삽화와 달리 시각적으로 단순하다. 학생 피드백("그림이 너무 단순하다")이 지목한 지점과 겹칠 가능성이 있다(검증은 이 조사 범위 밖).
