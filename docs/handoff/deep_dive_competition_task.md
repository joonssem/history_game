# Deep-dive MUD 경쟁 개선 과제

## 목적

두 에이전트가 서로 다른 Deep-dive MUD를 독립적으로 개선하고, 실제 플레이와 검토 결과를 비교하여 프로젝트의 다음 방향을 찾는다.

이번 과제의 목표는 콘텐츠를 무조건 늘리는 것이 아니라 다음을 함께 검증하는 것이다.

- 초등학교 5학년이 역사 자료를 읽고 판단할 수 있는가
- 핵심 경로와 분기 구조가 학습적으로 의미 있는가
- 인터랙티브 시뮬레이터가 단순 클릭이 아니라 역사적 판단을 요구하는가
- 실제 플레이 시간이 설계 의도에 맞는가
- 학생이 빠르게 정답만 찾는 경로가 존재하는가

## 담당 범위

| 담당 | 대상 파일 | 원칙 |
|---|---|---|
| Codex | `data/mud/deep_three_kingdoms.json` 및 필요한 공통 시뮬레이터 코드 | prehistoric 관련 파일을 수정하지 않는다 |
| Claude Code | `data/mud/deep_prehistoric.json` 및 필요한 공통 시뮬레이터 코드 | three_kingdoms 관련 파일을 수정하지 않는다 |

공통 코드 수정이 불가피하면 먼저 상대 에이전트에게 알리고, 변경 이유와 영향 범위를 기록한다. 가능하면 각 MUD의 데이터와 기존 simulator 모드 조합 안에서 해결한다.

## 공통 작업 순서

1. 현재 MUD의 모든 stage, 선택지, 분기, simulator, 엔딩을 읽는다.
2. 초등학교 5학년 수준에서 어려운 표현, 역사적 맥락 오류, 정답 편향을 기록한다.
3. simulator별로 입력 방식, 완료 조건, 피드백, 역사적 판단 요소를 점검한다.
4. 수정 전 예상 플레이 시간을 기록한다.
5. 최소 범위로 개선한다.
6. 브라우저에서 실제 플레이하며 시간을 측정한다.
7. 수정 후 시간, 난이도, 시뮬레이터 품질, 회귀 여부를 보고한다.

## 반드시 확인할 항목

### 콘텐츠

- 서술문·선택지·자료·시뮬레이터·보상 유물이 같은 역사적 학습 목표를 가리키는가
- 정답이 문장 길이, 위치, 교과서 표현만으로 드러나지 않는가
- 실패 경로가 단순한 벌점이 아니라 다시 생각할 근거를 제공하는가
- 5학년 학생이 한 번에 이해하기 어려운 어휘가 설명되는가
- 폭력·전쟁·정치적 판단이 연령에 맞는 방식으로 표현되는가

### 인터랙티브 시뮬레이터

- 학생이 실제로 조작할 수 있는가
- 아무 입력 없이 완료되거나 연속 탭만으로 완료되지 않는가
- 입력 결과가 역사적 선택 또는 자료 해석과 연결되는가
- 성공·실패 피드백이 왜 그런 결과가 나왔는지 설명하는가
- 터치 화면에서 조작 가능한가
- 시뮬레이터가 텍스트 문제와 중복되지 않는가

### 플레이 시간

다음 시간을 구분하여 기록한다.

- 전체 최초 플레이 시간
- 정답을 빠르게 찾았을 때의 시간
- 실패·재시도 포함 시간
- 각 simulator의 체감 시간과 실제 시간
- 교실에서 친구와 정보를 공유했을 때 예상되는 단축 가능성

`30min+` 메타데이터를 그대로 전제하지 말고 실제 측정값과 비교한다. 30분에 미치지 않더라도 콘텐츠를 억지로 늘리지 말고, 탐험·자료 비교·추론의 필요성을 먼저 검토한다.

## 평가 기준

각 에이전트는 다음 항목을 5점 척도로 자기 점검한다.

| 항목 | 1점 | 5점 |
|---|---|---|
| 역사적 정합성 | 문맥 충돌이 있음 | 모든 요소가 같은 학습 목표로 연결됨 |
| 5학년 적합성 | 이해·읽기 부담이 큼 | 혼자 읽고 핵심을 파악 가능 |
| 근거 기반 판단 | 정답 추측 가능 | 자료를 보아야 판단 가능 |
| simulator 상호작용 | 장식·반복 클릭 | 입력과 역사적 결과가 연결됨 |
| 피드백 품질 | 정답 여부만 표시 | 판단 이유와 자료 근거를 설명함 |
| 플레이 시간 | 지나치게 짧거나 불명확 | 의도한 탐구 시간과 실제 시간이 근접 |
| 모바일/태블릿 조작성 | 조작 실패 가능 | 터치로 안정적으로 조작 가능 |

점수는 경쟁의 승패보다 다음 공통 설계 원칙을 찾기 위한 자료로 사용한다.

## 결과 보고 형식

각 담당자는 다음을 보고한다.

```text
1. 수정한 파일
2. 발견한 핵심 문제 3개 이내
3. 수정한 내용과 수정하지 않은 내용
4. simulator별 입력·완료 조건·피드백 평가
5. 실제 플레이 시간 측정값
6. 초등학교 5학년 적합성 판단
7. 5점 평가표
8. 남은 위험과 다음 실험 제안
```

## 범위 제한

- React, Vue, 게임 엔진, 외부 패키지를 추가하지 않는다.
- 백엔드·Supabase·Realtime·로그인·타이쿤은 이번 과제에서 구현하지 않는다.
- 상대 에이전트의 담당 MUD를 수정하지 않는다.
- 유물 등급이나 경쟁 시스템은 설계 아이디어로만 평가하고 이번 과제의 핵심 구현 범위로 확장하지 않는다.
- 새로 발견한 별도 아이디어는 현재 작업에 섞지 않고 `INBOX.md` 또는 `BACKLOG.md`에 기록한다.

## 완료 조건

두 MUD 모두 다음 조건을 만족해야 과제를 완료로 본다.

- JSON 구조 검사 통과
- 브라우저에서 시작부터 엔딩까지 플레이 가능
- 모든 simulator가 입력·완료·피드백 흐름을 가짐
- 핵심 선택지가 자료 근거 없이 문장 형태만으로 풀리지 않음
- 실제 플레이 시간 측정 결과가 기록됨
- 변경 사항과 남은 문제를 walkthrough 또는 결과 보고에 남김

## Codex 중간 결과 — `deep_three_kingdoms`

2026-09-01 기준으로 다음을 반영하고 브라우저에서 확인했다.

- 1장 황산벌: 연속 터치 게이지를 세 가지 역사 단서 탐색으로 변경
- 4장 매소성: 산성 방진·보급로 차단 두 행동을 모두 수행해야 선택지 해제
- 5장 기벌포: 움직이는 적 함선 네 척을 맞혀야 선택지 해제
- 7장 천문령: 좁은 협곡·높은 지대·동모산 이동로 단서 세 가지 탐색
- 최초 진입부터 진엔딩까지 브라우저 기준 약 1분 43초. 자동 조작 기준이므로 학생 실제 시간의 확정값으로 사용하지 않음
- JSON·MUD 무결성·MUD 계약·시뮬레이터 런타임 검사 통과

남은 확인:

- 초등학교 5학년 학생의 실제 독해 시간과 조작 난이도
- 함선 조준이 태블릿 터치에서도 충분히 쉬운지
- 역사 단서 탐색이 선택지 정답 추측이 아니라 근거 읽기로 이어지는지
- 전체 학급 환경에서 친구 간 정보 공유가 플레이 시간을 얼마나 줄이는지
