## 업그레이드 후보 (효과 큰 순)

1. **장면 일러스트를 SVG로 교체** — 캔버스 도형 대신 시대별 한지 수묵·채색풍 SVG 장면(명량 해협, 고인돌, 한양도성, 개항 항구 등). 핫스팟 좌표·완료 로직은 그대로 두고 배경만 바꾼다. 라벨 겹침은 위치 보정으로 해결. 새 라이브러리 없음.
2. **인물 초상 세트** — 이모지를 시대별 SVG 인물(이순신·세종·상인·학생 등)으로. 이름 칩 틀은 유지.
3. **협동 활동 삽화** — 활동마다 역할 카드 아이콘·자료 삽화·한눈에 보는 지도/연표 한 장. 교과서 쪽수 범위 안의 소재만 쓴다(저작권 있는 교과서 그림은 쓰지 않고 새로 그린다).
4. **완료·보상 연출** — 유물 카드를 도장·두루마리 풍으로, 단서 발견 때 짧은 모션, `prefers-reduced-motion` 존중.
5. **디자인 토큰 정리** — 포털·MUD·협동의 색·버튼·반응형 경계를 한 기준으로(`P2-UI-COOP-INQUIRY-DESIGN`과 합침).

## 제약과 위험

- 공용 엔진(`episode.js`·`pacing.js`·`cooperative.css`)은 현재 수정 금지. 협동 쪽은 활동 폴더 안 CSS/SVG 추가나 별도 승인이 필요하다.
- 교과서 그림·사진은 쓰지 않는다. 역사 고증이 필요한 그림(복식·배·건물)은 5학년에게 오개념을 주지 않도록 근거 이미지(공공누리 박물관 자료 등)로 대조한다.
- 모든 장면에 텍스트 대안(`aria`) 유지, 태블릿 터치 대상 44px 이상.
- 파일 크기: SVG 인라인 장면 105개는 `mudSimulators.js`를 크게 키우므로 `assets/scenes/*.svg` 분리 로드가 낫다(정적 호스팅이라 문제 없음).
- 범위가 커서 한 번에 하지 않는다: 시범 2~3장면 → 사용자 검토 → 시대 단위로 확장.
