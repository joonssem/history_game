## 1. 앞의 두 게임과 다른 점

| 항목 | 세도정치 / 갑신·동학 | 암살 |
|---|---|---|
| 단위 | 포인트 | **독립자금(원)**. 시작 0, 모자라면 음수(PPT: “부족하면 넉넉한 친구에게 빌리세요”) |
| 신분 | 선택·전환 있음 | **없음. 모두 같은 신분**(PPT 3장). A/B 시작 선택·제비뽑기 없음 |
| 에피소드 | 21 / 38 | **33**(CHAPTER 1910년대 1~12 / 1920년대 13~21 / 1930년대 22~32 / 마무리 33) |
| 장면 종류 | 선택·상황 | 객관식, **주관식(퍼즐)**, **지역 이동(비용)**, 상황 발생 |
| 장비 | 없음 | 마우저 권총·M1 소총·일본인 콧수염·나시카 망원경 획득 성공/실패 → 이후 선택의 상한(일본군 위치 4/7개, 폭탄 상자 1/2개) |
| 이동경로 | 없음 | 종이표는 지도에 화살표로 그린다 → 앱은 이동한 도시를 **자동 기록** |
| 마무리 | 점수표·한줄 정리 | 독립운동가 명언 4개 빈칸, 나의 명언 + 짝꿍 평가, 획득 무기, 이동경로, 느낀점 |
| 게임 오버 | 끝까지 진행 | 에피소드 1에서 “일제에 협력”을 고르면 **즉시 GAME OVER(+10,000원, 게임 참여 불가)** |

- 이상적인 경로의 최종 자금: −8원(에피소드 32의 −200이 커서 모두 음수에 가깝다). 승패 없는 게임이라 점수 표시는 “자금”으로만 한다.
- 종이표 회색 칸(선택 없음) = 에피소드 2, 3, 6, 7, 12, 13, 17, 24, 25, 27, 28, 29, 32 → 앱은 선택이 없는 장면(상황·이동)으로 자동 판정한다.
- 이동 순서(앱이 자동 기록): 경성 →(3) 만주 →(7) 경성 →(13) 만주 →(17) 군산 →(24) 상해 →(28) 경성. 이동 비용 합계 −103원.

## 3. 종이표의 나머지(마무리 화면)

- **독립운동가 명언 빈칸 4개**(왼쪽 이름 칸도 비어 있음): 이회영 “삶과 (죽음)은 … (죽음)을 두려워해…”, 김좌진 “삼천리 금수강산에 (왜놈)이 웬 말인가…”, 신채호 “(역사)를 잊은 민족은…”, 윤봉길 “(독립)은 머지않아 꼭 실현되리라…”. 앱: 이름·빈칸 입력 + ‘정답 보기’.
- **획득 무기** 4개 성공/실패 → 앱이 자동 표시.
- **이동경로** → 앱이 도시 순서를 자동 표시(지도에 직접 그리는 부분은 종이 활동).
- **느낀점** → 입력 칸.
- PPT에서 학생이 직접 푸는 퍼즐(사진 고르기·숫자 기억·상자 섞기·사람 찾기)은 TV 화면의 활동이고 앱은 결과 입력만 받는다.

## 4. 구현 방침

1. `cooperative-mud/assassination-scoreboard/`(`game.js`·`app.js`·`index.html`·`board.css`). 기록을 다시 계산하는 `derive` 구조 유지.
2. 장면 종류: `choice`(선택) · `situation`(상황) · `move`(이동, 위치 추적) · `quiz`(주관식: `numbers` 일본군 위치 / `texts` 3문제 / `text` 한 칸 / `boxes` 상자) · `final`(에피소드 33).
3. 장비는 플래그로 두고 퍼즐의 입력 상한(권총 4·소총 7, 상자 1·망원경 2)을 자동 적용한다.
4. 교사용 화면(`teacher/boards.js`)에 탭을 더하고, 허브 카드·`TEACHING.md`를 갱신한다.
5. 검증: PPT 좌표 대조 스크립트(스크래치), `scripts/coop/check_assassination_scoreboard.js`(규칙·손계산), `e2e_assassination_scoreboard.js`(Chrome).

## 5. 앞의 점수판과 같이 가져가는 것

- 확인 버튼 한 번 더, 되돌리기, 교사가 알려 준 점수 가감(수동), 새로고침 후 이어하기, 이름·학번 입력 없음, 승패 없는 게임 안내.

## 6. 판단(권장안으로 구현, 바꾸고 싶으면 알려 주세요)

1. **주관식 채점**: 정답이 텍스트·숫자로 PPT에 있는 곳(에피소드 15·18·19·20·22)은 학생이 입력하면 앱이 채점한다(띄어쓰기·“장군/가마/명” 무시). **정답이 그림에만 있는 에피소드 11**은 교사가 정답을 말한 뒤 학생이 ‘정답/오답’을 누른다.
2. **에피소드 15의 최고 구간**: PPT는 “5개 정답 +50”인데 정답 번호가 6개(0,1,2,4,7,9)다. **5개 이상 +50**으로 처리한다. 틀린 번호를 써도 따로 깎지 않고 개수 상한(권총 4/소총 7)만 적용한다.
3. **에피소드 1 “일제에 협력”**: +10,000원과 GAME OVER 화면(게임 참여 불가)을 보여 주고 끝낸다. “되돌리기”로 돌아갈 수 있다.
4. **에피소드 30**: 슬라이드의 정답(2번 상자)을 앱이 판정한다. 망원경이 없으면 1개, 있으면 2개까지 고를 수 있다.
5. **에피소드 33**: 명언을 쓰고 짝꿍이 정한 평가(표창/상장/명단 탈락)를 누른다. 자금 변화 없음.
6. **자금이 음수**가 되어도 막지 않는다. “부족하면 넉넉한 친구에게 빌려요” 안내를 점수 막대 아래에 작게 보여 준다.
7. **이동경로**는 도시 순서만 자동으로 보여 주고 지도에 그리는 것은 종이 활동으로 남긴다.
