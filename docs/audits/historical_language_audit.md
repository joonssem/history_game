# MUD 역사 서술 품질 감사

## 감사 목적

- 초등학생이 가상 분기나 게임적 연출을 역사적 사실로 오해하지 않도록 한다.
- 인물의 결단만으로 역사가 결정되었다는 영웅 중심·단일 원인 설명을 줄인다.
- 전쟁과 식민지 피해를 적 집단 비하, 섬멸, 국가 소멸 체험으로 소비하지 않는다.
- `최초`, `유일`, `완전`, 수치 비교는 출처가 뒷받침하는 범위 안에서만 사용한다.

## 판정 기준

| 등급 | 판정 | 처리 원칙 |
|---|---|---|
| A | 자료에 근거한 관찰·비교·추론 | 유지 |
| B | 강조 표현이 있으나 오개념 위험이 낮음 | 후속 다듬기 |
| C | 단일 원인, 과도한 인과, 사실처럼 제시한 가상 결과 | 우선 교정 |
| D | 집단 비하, 섬멸·몰살 체험, 피해를 영웅 놀이로 재현 | 즉시 재설계 |

`모든 단서를 확인했다`처럼 활동의 완료 상태를 나타내는 문장은 절대 표현 감사 대상에서 제외한다. `역사의 IF`라는 형식도 그 자체로 오류는 아니지만, 일어나지 않은 결과를 확정하거나 공포·죄책감으로 정답을 유도하면 C 또는 D로 판정한다.

## Phase 25 교정 결과

| MUD | 주요 문제 | 교정 방향 |
|---|---|---|
| 일제 말기 통치와 저항 | 원고 하나가 없으면 한국어와 대한민국이 사라졌다는 단정 | 언어 억압의 영향과 원고의 사료적 의미를 구분 |
| 전후 재건 | 경제 성장을 개인의 끈기와 교육 한 요소로 환원 | 시민·정책·산업·국제 원조 등 복합 조건 제시 |
| 세종 시대 | 칠정산이 농업 생산량을 높였다는 직접 인과, 측우기 `세계 최초` 단정 | 관측·역법·표준 측정의 확인 가능한 의미로 제한 |
| 명량대첩 | 수군 해체가 곧 조선 패망이라는 가상 결과, 적선 궤멸의 극적 묘사 | 해상 보급·선박·화포·물길 자료를 비교하는 판단으로 전환 |

## 남은 위험과 처리 순서

1. **Deep-dive 전쟁 서사(D) — 완료**: `deep_three_kingdoms`, `deep_joseon`, `deep_modern`, `deep_prehistoric`의 몰살·섬멸·국가 소멸·집단 비하 선택지를 자료 기반 판단으로 재설계했다.
2. **Regular 구형 실패 분기(C) — 완료**: 25개 Regular MUD의 `역사의 IF` 표지를 `자료 해석`으로 바꾸고, 가상 결말 대신 도구·유물·기록이 알려 주는 조건을 다시 확인하게 했다.
3. **최초·수치 주장(B/C) — 완료**: 고조선 법, 고려 금속활자, 개항기 시설, 매소성·명량 병력 수처럼 기준이 필요한 표현을 공식 자료의 범위와 맞췄다.
4. **용어 일관성(B) — 완료**: 사료 속 시대 용어와 학생 안내 문장을 구분하고, 집단 호칭·문해·생활 신앙 관련 표현을 중립적으로 정리했다.

## Phase 26 Deep-dive 재설계 결과

- 선사: 포로 노비화와 가혹한 처벌을 학생이 명령하던 장면을 무기·무덤·법 기록에서 계층과 사회 모습을 해석하는 활동으로 전환했다.
- 삼국·남북국: 당군 섬멸, 유민 몰살, 민족사 소멸 표현을 지형·행정 기구·집단 이동 자료를 연결하는 판단으로 바꿨다.
- 조선: 일본군을 본질적으로 백병전에 능한 집단으로 일반화하거나 조선 멸망을 확정하던 피드백을 선박·화포·보급로 비교로 바꿨다.
- 근현대: 한국광복군 하나로 국제적 지위를 단정하거나 학도의용군 전투를 영웅 놀이로 재현하던 흐름을 복합 원인과 민간 경험 자료 비교로 바꿨다.

## 완료 조건

- 반사실적 결과가 확정된 사실처럼 제시되는 C급 문장 0건
- 집단 비하나 몰살·섬멸을 정답 행동으로 요구하는 D급 활동 0건
- 유지하는 `최초`·전투 수치에 해당 주장 범위를 뒷받침하는 출처 존재
- 수정 뒤 MUD 무결성·계약·활동 시간·런타임 검증 통과

## Phase 27 Regular 실패 분기 정규화 결과

- 25개 Regular MUD의 실패 배지와 본문에서 `역사의 IF`를 `자료 해석`으로 통일해, 가상 실패가 실제 역사의 다른 결말처럼 읽히는 문제를 줄였다.
- 일제 피해 증언, 중인의 전문 기술과 상민·노비의 노동, 개항기 교통 시설은 하나의 집단·자료가 이후 사회 전체를 결정했다는 서술을 여러 자료와 조건을 비교하는 문장으로 교정했다.
- 지형·도구·유물의 기능을 확인하는 실패 피드백은 유지했다. 이는 반사실적 공포가 아니라 선택한 자료와 물성의 불일치를 설명하는 학습 피드백이기 때문이다.

## Phase 28 `최초`·수치 주장 사실 범위 감사

| 주장 | 판정 | 반영 |
|---|---|---|
| 명량 13척·133척 | 범위 구분 필요 | 일본 수군 전체 약 200~300척, 교전 약 133척, 격파 31척으로 구분 |
| 매소성 당군 20만·말 3만여 필 | 사료 기록이나 병력 수 논쟁 존재 | 『삼국사기』 기록임을 밝히고 과장 가능성 병기 |
| 모내기 노동력 1/5 | 연결 근거로 확정 불가 | 제초 횟수와 볍씨를 줄였다는 확인 가능한 효과로 조정 |
| 경성 전차 아시아 최초·도쿄보다 먼저 | 비교 기준 불명확 | 1899년 운행한 우리나라 최초의 전차로 범위 한정 |
| 상정고금예문 세계 최초 | 실물과 기록 구분 필요 | 1230년대 금속활자 인쇄 기록, 실물 미전승으로 조정 |
| 고조선 50만 전과 화폐 | 해석 주의 필요 | 사유재산·신분 차이는 제시하되 화폐의 보편 사용은 단정하지 않음 |
| 현재 세계 10대 경제 대국 | 시점에 따라 변동 | 순위 표현을 제거하고 산업화·민주화의 복합 과정으로 설명 |

## Phase 29 집단 호칭·가치 편향 감사

- 학생 안내 문장의 `왜군`은 `일본군`으로 통일했다. `왜`처럼 당시 국가·집단을 가리키는 역사 용어와 사료 속 직접 인용은 문맥을 확인해 유지할 수 있다.
- `까막눈`, `미신`, `귀신의 의술`, `짐승처럼` 등 사람이나 생활 문화를 낮춰 부르는 표현을 문해 환경·자료 근거·제도적 차별을 설명하는 말로 바꿨다.
- 성리학 전체를 낡은 학문, 실학자를 깨어 있는 영웅으로 대비하던 서술을 학자별 관심과 개혁안의 공통점·차이를 비교하는 활동으로 조정했다.
- 독립·광복은 `민족의 혼`보다 언어·이름·사진·기록·상징 자료로 설명하고, 판소리와 전통문화는 `위대한 민족 예술` 같은 가치 평가를 줄였다.
- Deep-dive 4종의 엔딩은 국가의 찬란함이나 영웅적 성공을 평가하는 구조에서 `자료 종합·부분 해석·재검토` 구조로 바꿨다.
