# Regular IF(재시도) 스테이지 교사 검토 우선순위 목록

> [`if_stage_audit.md`](if_stage_audit.md)(구조 감사)의 83개 잔여 신호를 교사가 검토하기 쉬운 순서로 재배열한 목록입니다. 실제 문장 수정은 하지 않았습니다 — 어떤 스테이지부터 볼지 우선순위만 정했습니다.

## 분류 기준

- **둘 다 미달**: 근거 설명 120자 미만 **이고** 자료·비교 단서 2개 미만 (구조적으로 가장 부실)
- **한쪽만 미달**: 둘 중 하나만 기준 미달 (상대적으로 양호)
- **민감 주제**: 일제강점기·독립운동·전쟁·병자호란·거란전쟁 등 이 프로젝트가 별도 정서 안전 원칙(D-011 계열)을 적용해 온 3단원 및 관련 2단원 파일. 같은 부실도라도 민감 주제는 오독 위험이 더 크므로 우선한다.

| 순위 | 조건 | 개수 | 근거 |
|---|---|---:|---|
| 1 | 둘 다 미달 + 민감 주제 | 14 | 가장 부실하고 오독 위험도 가장 크다 |
| 2 | 둘 다 미달 + 비민감 주제 | 15 | 부실하지만 오독 위험은 상대적으로 낮다 |
| 3 | 한쪽만 미달 + 민감 주제 | 16 | 구조는 양호하나 민감 주제라 재확인 가치가 있다 |
| 4 | 한쪽만 미달 + 비민감 주제 | 38 | 우선순위 가장 낮음, 표본만 확인해도 충분할 수 있다 |

## 사용 방법 제안

1. 1순위 14곳부터 실제 화면(`MudEngine.openMUD(mudId)` → 오답 선택 → 해당 재시도 스테이지)을 열어 서술이 충분한지 판단한다.
2. 부족하다고 판단되면 스테이지 ID를 알려주면, 이번 세션에서 검증한 "단서 인용형 재작성" 기법으로 다시 쓴다.
3. 이미 충분하다고 판단되면(짧아도 의도된 정서 안전 문구 등) 그대로 두고 다음 스테이지로 넘어간다 — 이 목록은 강제 수정 목록이 아니라 검토 순서표다.
4. 4순위는 시간이 부족하면 건너뛰어도 무방하다.
