# 학생 체험 피드백 기반 아이디어 노트

> 작성일: 2026-09-01  
> 근거: 1단원 2·3차시 학생 직접 체험 및 관찰  
> 상태: 보관. 후속 기획 재개 전까지 구현하지 않음.

## 0. 오늘의 현장 검증 결과

수업 종료 10분 전, 학생들이 빠르게 진행할 것을 예상하고 1단원 2차시와 3차시 활동을 함께 제시했다. 학생들은 두 활동을 모두 4분 이내에 완료했다. 따라서 현재 활동은 설계 목표인 10분 이내에는 들어오지만, 실제 빠른 학습자에게는 체험·자료 해석·성찰 시간이 충분히 발생하기 전에 종료될 수 있음이 확인되었다.

빠르게 완료한 학생들이 오타 또는 문맥 문제를 찾아 교사에게 제시했다. 이는 학생들이 단순히 버튼만 누른 것이 아니라 콘텐츠의 이상 여부를 관찰할 수 있었음을 보여주지만, 동시에 짧은 활동에서 오류가 학습 경험보다 먼저 눈에 띌 수 있다는 신뢰성 문제도 드러낸다.

유물을 얻은 학생이 “이 유물로 무엇을 하나요?”라고 질문했다. 이 질문을 들은 다른 학생은 유물로 경쟁할 수 있으면 좋겠다는 의견을 냈고, 또 다른 방향으로 ‘역사 타이쿤’으로 발전시키자는 아이디어가 나왔다. 즉 경쟁과 타이쿤은 사전 기획된 요구라기보다, 보상 획득 후 다음 행동을 기대하는 과정에서 자연스럽게 나온 확장 요구다.

## 1. 학생 목소리 요약

학생들은 활동을 “재밌다”고 느꼈다. 동시에 정답을 역사 자료보다 선택지의 겉모양으로 추측할 수 있고, 전체 난이도가 낮다는 반응을 보였다. 실제로 1단원 2·3차시 두 활동을 4분 이내에 완료했으며, 빠른 완료 과정에서 오타 또는 문맥 문제를 찾아 교사에게 제시했다. 유물을 얻은 뒤 “무엇을 하느냐”는 다음 행동을 기대했고, 그 질문에서 친구와 경쟁하는 기능과 역사 속 사회를 운영하는 ‘역사 타이쿤’ 아이디어가 파생되었다.

## 2. 핵심 문제 정의

### 학습 문제

현재 일부 선택지는 긴 문장, 구체적인 설명, 정답처럼 보이는 어휘 때문에 자료를 읽지 않아도 답을 추측할 수 있다. 여기에 활동 완료 조건이 짧게 느껴져 빠른 학생이 2개 활동을 4분 안에 끝낼 수 있다. 이는 “유적·유물을 근거로 추론한다”는 제품 목표와 맞지 않으며, 남은 수업 시간을 학습적으로 활용할 후속 활동이 필요하다는 뜻이다.

### 동기 문제

유물은 현재 주로 완료 보상과 도감 수집의 역할을 한다. 학생 입장에서는 유물을 얻은 뒤 사용·성장·변화로 이어지는 다음 목표가 부족하다.

### 사회적 놀이 문제

친구와 비교하고 싶은 욕구는 확인되었지만, 로그인·서버·실시간 멀티플레이는 현재 제품 범위 밖이다. 따라서 개인 기기에서 안전하게 운영되는 비교·협력부터 설계해야 한다.

### 콘텐츠 신뢰 문제

1단원 3차시 `regular_neolithic`에서 2단계의 농기구 설명과 토기 선택지, 3단계의 토기 설명과 가락바퀴·뼈바늘 선택지가 서로 어긋났다. 이 문맥 오류는 2단계 토기, 3단계 의생활 흐름에 맞게 설명 문구를 정렬해 해결했다.

## 3. 아이디어 묶음

### A. 자료 기반 선택지 개선 — 우선 검토

- 선택지 길이를 비슷하게 맞춰 ‘긴 문장=정답’ 단서를 제거한다.
- 정답 선택지에만 전문 용어나 자세한 설명을 몰아넣지 않는다.
- 먼저 유물·환경·기록 단서를 확인해야 선택지가 충분히 이해되도록 한다.
- 오답도 그럴듯한 역사적 선택으로 만들고, 선택 후에는 자료와 연결된 이유를 보여준다.
- 정답 위치를 고정하지 않고, 무작위 표시가 교육적 단서를 훼손하지 않는지 함께 점검한다.

목표는 문제를 어렵게 만드는 것이 아니라, 문장을 읽고 근거를 비교해야 풀 수 있게 만드는 것이다. 단, Regular MUD 자체를 무리하게 늘려 10분을 채우기보다는 기본 활동과 선택형 후속 활동을 분리하는 방안도 검토한다.

### B. 유물 활용 — 작은 기능부터

유물을 단순히 모으는 데서 끝내지 않고 다음과 같은 행동으로 연결한다.

1. **유물 전시관 꾸미기**: 시대별·주제별 전시 공간을 채우고, 전시 조합에 따라 짧은 해설을 연다.
2. **유물 복원 퍼즐**: 깨진 모양, 무늬, 쓰임 단서를 맞춰 복원한다.
3. **유물 조합 탐구**: 토기+농기구처럼 함께 놓인 자료를 보고 당시 생활을 추론한다.
4. **유물 카드 성장**: 같은 유물 카드를 강화하는 대신, ‘관찰·비교·추론’ 학습 기록으로 카드 정보가 확장된다.
5. **유물 탐험 미션**: “강가에 정착한 까닭을 설명할 유물 2개 고르기”처럼 기존 학습 목표와 연결한다.

첫 실험 대상으로는 서버 없이 구현 가능한 ‘전시관 꾸미기’ 또는 ‘유물 복원 퍼즐’이 적합하다. 빠르게 본 활동을 끝낸 학생이 바로 이어서 선택할 수 있는 3~5분짜리 보너스 활동으로 제공하면 수업 잔여 시간을 흡수할 수 있다.

### C. 친구와 함께하는 유물 활동

경쟁 점수만 강조하기보다 학습 결과를 비교하거나 협력하는 구조를 우선한다.

- **교실 컬렉션 비교**: 각자 도감에서 얻은 유물 수·시대별 완성률만 닉네임 없이 비교한다.
- **오늘의 유물 퀴즈**: 같은 문제를 풀고 근거 선택 여부와 점수를 개인 기기에 표시한다.
- **짝꿍 공동 발굴**: 두 학생이 서로 다른 단서를 보고 하나의 유물 설명을 완성한다.
- **시대별 전시 대결**: 제한된 유물로 가장 설득력 있는 전시 구성을 만들고 발표한다.

현재 범위를 고려하면 실시간 순위표보다 교사가 제시한 코드·문제 세트로 결과를 비교하는 방식이 안전하다. 이름, 계정, 서버 저장, 공개 순위는 별도 결정이 필요하다.

### D. 역사 타이쿤

역사적 사실을 마음대로 바꾸는 도시 건설 게임보다, 자료를 근거로 선택하고 제약 속에서 생활을 꾸리는 탐구형 운영 게임으로 정의한다.

- **신석기 마을 타이쿤**: 물, 식량, 농경, 움집, 공동체를 관리한다.
- **고구려 성 운영**: 지형, 식량, 방어, 교류 자료를 보고 선택한다.
- **조선 마을 운영**: 농업, 시장, 신분 질서, 재해 대응을 자료와 함께 살핀다.
- **개항기 항구 운영**: 교역의 이익과 외세·기술·주권 문제를 균형 있게 판단한다.

초기 프로토타입은 하나의 시대와 5~7개의 선택만 포함하는 5~10분 내외 선택형 활동으로 제한한다. 기본 MUD를 빨리 끝낸 학생에게는 자원 운영·추가 선택을 포함한 확장 모드로 연결할 수 있다. 선택 결과에는 점수만 주지 말고 “어떤 자료를 근거로 한 선택인지”와 역사적 한계를 설명한다.

## 4. 제안 우선순위

| 우선순위 | 아이디어 | 이유 |
|---|---|---|
| P1 | 선택지 길이·표현 편향 감사 및 수정 | 현재 학습 효과를 직접 방해하는 문제 |
| P1 | 신석기 2~3단계 문맥 정합성 수정 | 학생이 실제로 발견한 오류 후보 |
| P1 | 유물 복원 또는 전시관 미니 기능 | 기존 도감과 연결하기 쉽고 서버가 불필요함 |
| P2 | 교실용 유물 비교·협력 활동 | 친구와 함께하고 싶은 요구를 안전하게 반영함 |
| P2 | 1개 시대 역사 타이쿤 프로토타입 | 규모가 크므로 작은 수직 슬라이스가 필요함 |

## 5. 다음 검증 질문

- 선택지 길이를 비슷하게 바꾸면 학생이 실제 자료를 더 읽는가?
- 학생이 1단원 2·3차시를 4분 이내에 완료한 원인은 읽기 속도, 선택지 구조, 시뮬레이터 완료 조건 중 무엇인가?
- 학생이 “왜 이 답을 골랐는지” 유물이나 환경 단서로 설명할 수 있는가?
- 유물 활용 기능이 학습 활동으로 인식되는가, 단순 장식·수집으로 인식되는가?
- 유물을 얻은 직후 학생이 기대하는 ‘다음 행동’은 전시, 복원, 교환, 경쟁, 운영 중 무엇인가?
- 경쟁보다 협력·발표 구조를 학생들이 더 선호하는가?
- 타이쿤에서 역사적 제약을 재미있는 규칙으로 받아들이는가?
- 신석기 2·3단계는 교과서 및 원래 의도와 비교했을 때 어떤 순서가 맞는가?

## 7. 오늘의 해석

이번 결과는 활동을 단순히 길게 만드는 것보다, 빠른 완료 이후에도 학습을 이어갈 수 있는 ‘다음 층’을 설계해야 한다는 신호다.

1. **기본층**: 1개 차시 MUD를 자료 기반으로 정확하게 완료한다.
2. **확장층**: 획득한 유물로 복원·전시·추론 미션을 수행한다.
3. **사회적 층**: 친구와 결과를 비교하거나 공동 전시를 만든다.
4. **탐구층**: 역사 타이쿤에서 자료와 제약을 바탕으로 운영 결정을 내린다.

빠른 학생에게는 확장층을 선택적으로 제공하고, 기본층의 학습 목표를 달성하지 못한 학생에게는 보충 자료를 제공하는 방식이 적절하다.

## 6. 실행 전 원칙

- 학생 반응을 근거로 하되, 즉시 기능을 추가하지 않고 작은 실험 단위로 검증한다.
- 재미 요소는 자료 읽기와 역사적 추론을 강화하는 방향으로만 사용한다.
- 경쟁 기능은 개인정보와 공개 순위를 최소화하고 협력 대안을 함께 제공한다.
- 역사 타이쿤은 사실을 임의로 왜곡하거나 폭력·정복을 보상하는 구조를 피한다.
- 구현 전 각 아이디어를 `BACKLOG.md`에서 우선순위화하고 별도 구현 계획으로 분리한다.
