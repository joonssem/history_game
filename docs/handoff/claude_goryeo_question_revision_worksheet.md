# 질문하고 고쳐 보기 — 학생용 활동지 (고려 15~18차시 공용)

- 작업: `TASK-20261002-OCT29-SUPPLEMENT` B
- 상태: `초안` — 인쇄 전 교사가 두 활동(관계/문화·생활) 중 쓰는 쪽의 문장틀 문구를 골라 확정한다.
- 쓰는 법: 모둠당 **1장**. 학생 이름·번호는 쓰지 않고 `모둠 번호`만 쓴다. 활동은 종이 한 장으로 끝내고 수업 뒤 모아서 버리거나 교사가 가져간다(사진 저장 금지).
- 질문 틀 3종(대상·근거·한계)은 `claude_joseon_late_teacher_sticky_wall.md` §1의 틀을 고려 활동에 맞게 고친 것이다.
- 이 활동지는 점수를 매기지 않는다. 정답을 맞히는 활동이 아니라 **근거로 질문하고 고치는 활동**이다.

## 학생용 인쇄본

```text
┌─────────────────────────────────────────────────────────────┐
│ 질문하고 고쳐 보기                              모둠 ____ 번 │
│ 활동: [ ]고려의 선택 회의 (주변 나라)  [ ]고려 문화 공방   │
└─────────────────────────────────────────────────────────────┘

① 우리 모둠의 처음 해석  (역할 카드 문장틀을 완성해서 쓰세요)
   ______________________________________________________________
   ______________________________________________________________

② 근거 2개  (서로 다른 역할 카드에서 하나씩)
   근거 1: ____________________________ (       카드)
   근거 2: ____________________________ (       카드)

③ 이 자료만으로는 알 수 없는 것
   ______________________________________________________________

④ 다른 모둠에게 할 질문  (아래 세 틀 중 하나 이상을 골라 쓰세요)
   [ ]대상 질문
      "그 해석은 [      ]에게는 어땠나요? [      ]에게는 어땠을까요?"
   [ ]근거 질문
      "그렇게 생각한 근거 하나를 다시 말해 주세요. 그 근거가 왜 그 해석과 이어지나요?"
   [ ]한계 질문
      "이 자료만으로는 알 수 없다고 한 것은 무엇인가요? 왜 알 수 없나요?"

   내가 한 질문(짧게): ____________________________________________

⑤ 받은 질문 뒤에 고친 해석
   [ ]고치지 않았다  → 그 이유: __________________________________
   [ ]고쳤다
   고친 부분: ____________________________________________________
   무엇 때문에 고쳤나: [ ]다른 역할의 자료  [ ]받은 질문  [ ]한계를 다시 생각함
```

## 모둠 안에서 말하는 법 (책상 위에 둘 안내)

- 먼저 자기 카드에 있는 내용을 자기 말로 말합니다. 카드를 그대로 읽지 않습니다.
- 친구의 말에서 "그 자료에는 뭐라고 나와 있어?"라고 물어도 좋습니다.
- 모르는 것은 "자료에 없어서 알 수 없어요"라고 말해도 됩니다.
- 한 사람이 다 쓰지 않고, 쓰는 사람은 돌아가며 정합니다.

## 교사용 안내

### 시간 (15분 활동 기준)

| 시간 | 단계 | 활동지 칸 |
|---|---|---|
| 8~10분 | 역할 카드 공유·공동 해석 | ①②③ |
| 3분 | 다른 모둠 발표 듣기, 질문 쓰기 | ④ |
| 2분 | 질문을 받고 해석 고치기 | ⑤ |

시간이 10분이면 ④를 말로만 하고 ⑤는 생략할 수 있다. ①②③은 줄이지 않는다.

### 질문 틀 쓰는 법

- 발표를 들은 모둠은 세 틀 중 **하나 이상**으로 질문한다. 세 틀을 다 써야 하는 것은 아니다.
- 질문은 칭찬이나 정답 말하기가 아니라 해석을 **검증**하는 것이다. "맞아요/틀려요"로 끝나는 말은 질문으로 보지 않는다.
- 순서는 `발표 → 질문 → 발표 모둠이 필요하면 해석 수정`이다. 수정하지 않아도 되고, 수정하지 않은 이유를 말하는 것도 좋은 응답이다.

### 활동별 예시 질문 (교사 참고, 학생 인쇄본에는 싣지 않음)

**관계(15~16차시)**
- 대상: "그 대응은 나라에는 도움이 됐다는데, 마을 사람들에게는 어땠을까요?"
- 근거: "거란 시기와 몽골 시기 중 어느 시기의 자료를 썼나요?"
- 한계: "한 사건의 결과만으로 고려의 모든 대외 관계를 말할 수 없다고 했는데, 어떤 자료가 더 필요한가요?"

**문화·생활(17~18차시)**
- 대상: "청자를 만든 사람과 쓴 사람은 같은 사람들이었을까요?"
- 근거: "가족·상속 자료와 청자·대장경 자료가 어떻게 이어지나요?"
- 한계: "이 자료에 나타나지 않은 사람은 누구일까요?"

### 활동지에서 보지 않는 것

- 학생 개인의 정답 여부, 글씨나 문장의 길이는 평가하지 않는다.
- 이름·번호, 개인 판단의 이유, 대화 원문은 기록하지 않는다. 기록은 `모둠 번호`와 아래 관찰 항목(§관찰 기록 연결)만 쓴다.
