## 3. 범위

### A. 보조 활동 자료 (사용자 선택 3번)

두 활동에 각각 한 묶음씩, **인쇄·화면 겸용 정적 자료**를 먼저 만든다.

| 묶음 | 대상 | 내용 |
|---|---|---|
| A-1 관계 | 15~16차시 | 거란 시기·몽골 시기 구분 카드, 서로 다른 역할 자료 4(+1)종 카드, "한 사건만으로 고려의 모든 대외 관계를 설명할 수 없다" 한계 카드 |
| A-2 문화·생활 | 17~18차시 | 만든 사람·사용한 사람·살아간 사람 자료 카드(청자, 상감, 직지·팔만대장경, 가족·상속, 벽란도 보조), 자료 한계 카드 |

- 역할 구성·핵심 주장·범위 원칙은 상위 계획 §4.3, §5.3을 따른다. 새 역할을 추가하지 않는다.
- 카드 문장 원칙은 상위 계획 §2의 가독성 원칙을 따른다: 한 문단 2~3문장, 낯선 용어는 바로 풀이, 핵심 근거 한 문장 구분, 정답 문장 직접 제공 금지.
- 모든 사실 서술은 `주장 → URL → 열람일 → 허용 범위 → 피해야 할 확대 해석` 출처 표를 먼저 만들고 대조한 뒤 카드에 옮긴다. 기존 `data/mud/regular_goryeo_*.json` 문장을 출처 확인 없이 복사하지 않는다.
- 형태는 **문서(.md)와 인쇄용 표** 로 한정한다. 시뮬레이터·작은 게임 등 `js/*.js`·`data/mud/*.json` 수정이 필요한 형태는 이번 범위가 아니며, 필요하면 사용자 승인 뒤 별도 묶음으로 BACKLOG에 올린다.

### B. 질문·수정 활동지와 관찰 기록 (사용자 선택 4번)

- **학생용 질문·수정 활동지 1종**: 두 활동 공용. 구성은 `처음 해석 → 근거 2개(서로 다른 역할) → 자료의 한계 → 다른 모둠 질문(대상·근거·한계) → 수정한 해석`. 질문 틀 3종은 기존 `docs/handoff/claude_joseon_late_teacher_sticky_wall.md` §1을 고려 활동에 맞게 바꿔 쓴다.

- 학생 이름·학번·개인 답안·대화 원문은 수집하지 않는다.

## 7. 수용 기준

- 모든 역할 카드에 그 역할만의 근거가 있고, 공동 해석은 서로 다른 역할 두 명의 자료 없이는 완성되지 않는다.
- 거란 시기와 몽골 시기를 구분한다. 백성 생활 영향을 포함한다. 거란·몽골을 현대 국가·민족과 단순 대응시키거나 공격적 성격으로 고정하지 않는다.
- 문화 활동은 기술·유물 특징만이 아니라 만든 사람·사용한 사람과 가족·상속·신분·제작 노동 근거, 그리고 자료로 알 수 없는 계층·지역을 포함한다.
- 3·4·5인 모둠에서 한 학생에게 역할을 겸임시키지 않고, 빠진 역할은 공통 자료로 보충한다.
- 기기·인터넷 없이 인쇄물만으로 10분 안에 운영 가능한 흐름이 있다.
- 전쟁 피해·신분 차이를 다루되 불필요하게 폭력적이거나 비하하는 표현이 없다.
