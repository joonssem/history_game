# 수업 관찰 체크리스트 — inquiry-task 파일럿 4편

> 라운드 3 지시서 §1-2. Codex의 첫 인계(`docs/handoff/claude_code_interaction_diversity_handoff_20260910.md` §6 P0)가 2026-09-10에 요구했으나 아직 만들어지지 않았던 문서다. 파일럿 4편(고려 문화·신석기·삼국·근대 개항)이 실제 학생에게 통했는지 수업 관찰 전에는 어떤 판단도 확정하지 않는다 — 이 문서는 관찰을 준비만 하고, 결과는 `EXPERIMENTS.md`에 별도로 기록한다.

## 1. 관찰 대상과 환경

- **대상**: 파일럿 4편(`regular_goryeo_culture`, `regular_neolithic`, `regular_three_kingdoms`, `regular_modern_open`) 전부. 학생 **3명 이상**, 가능하면 서로 다른 사회 교과 성취 수준(상·중·하)을 섞는다.
- **기기·뷰포트**: 아이패드 가로 **1180×820**, 휴대폰 세로 **390×844** 두 조건을 모두 관찰한다. 같은 학생이 두 기기를 다 쓸 필요는 없지만, 4편 전체가 두 뷰포트에서 최소 1회씩은 관찰되어야 한다.
- **진행 방식**: 교사가 옆에서 관찰하되, 막히지 않는 한 먼저 개입하지 않는다. "왜 그렇게 골랐는지" 정도만 자연스럽게 물어봐도 된다.
- **사전 준비**: 관찰 전 `docs/audits/inquiry_pilot_semantic_review.md`의 신규 수정 사항(근대 개항 1관문)이 실제 배포본에 반영됐는지 확인한다.

## 2. 공통 지표 (편마다 기록)

| 지표 | 기록 방법 |
|---|---|
| 완료 시간 | 편 시작~4관문 완료까지 초 단위. 목표 범위 **7~12분** |
| 무작위 클릭·전수 대입 행동 | 자료를 열지 않고 선택지를 순서대로 눌러보는지, 같은 조합을 반복 시도하는지 |
| 자료 연결을 **말로** 설명 | 두 개 이상의 근거를 연결해 "이래서 이렇다"고 말로 설명하는 순간이 있었는지(자발적/교사 질문 유도 구분) |
| 오답 뒤 스스로 수정 | 오답 피드백을 읽고 자료를 다시 확인해 고치는지, 아니면 답만 바꿔 눌러보는지 |
| 교사 개입 횟수 | 학생이 스스로 진행하지 못해 교사가 힌트를 준 횟수와 그 관문 |
| 조작이 막힌 지점 | 어느 관문·어느 조작(카드 순서, 지도 클릭, 근거 인벤토리 열기 등)에서 멈췄는지, 원인 추정 |

## 3. 편별 관찰 포인트

### 근대 개항 (`regular_modern_open`)
- 4관문에서 **한쪽 극단**(전차만으로 충분/불평등 조약이 모든 의미를 지운다)을 고르는 학생이 있는지, `requireLimit`이 실제로 그 선택을 막는지.
- 1관문에서 새로 추가된 "항구 개방 조항" 자료를 읽고 "개항의 계기"를 스스로 설명하는지, 아니면 불평등 조항만 보고 판단을 내리는지.

### 삼국 (`regular_three_kingdoms`)
- 4관문에서 **세 나라(백제·고구려·신라) 근거를 다 모으는 데** 막히는 학생이 있는지 — 특히 앞 관문에서 놓친 근거를 다시 찾으러 되돌아가는지.

### 신석기 (`regular_neolithic`)
- 4관문에서 환경·토기·의생활 **세 성격이 다른 근거**를 구분해 고르는지, 범주가 비슷해 보이는 토기·의생활을 섞어서 헷갈리는지.

### 고려 문화 (`regular_goryeo_culture`)
- 마지막 관문에서 **앞 관문 근거를 기억하는지** — 근거 인벤토리를 열어 확인하는지, 아니면 이름만 보고 추측해서 고르는지.

## 5. 결과 처리 원칙

- 관찰 결과를 즉시 요구사항으로 승격하지 않는다. `EXPERIMENTS.md`에 "관찰 → 가설 → 실험 → 결과 → 다음 결정" 형식으로 남기고, **결과 칸은 실제 관찰 전까지 비워 둔다.**
- 관찰 결과가 부정적이면(완료 시간이 크게 벗어나거나, 무작위 클릭이 자주 관찰되거나, 자료 연결 설명이 거의 없으면) 새 편 확장을 중단하고 파일럿 UX부터 재검토한다 — 새 편·새 게임 요소를 먼저 추가하지 않는다.
- 학생 개인정보(이름 전체, 얼굴 사진 등)는 기록지에 남기지 않는다. 학생 식별은 교사 내부용 약칭으로 충분하다.
